# 논문 내용 재검토 및 수정 기록

검토일: 2026-10-21. 대상은 기존 IEEEtran 원고와 공개 저장 결과다. 검토 출발 커밋은 `f6fd8a8`이며, 학습 자료·모델·비용·계획·실행 결과를 변경하지 않았다. 방법, 결과 수치, 연구 논리를 나누어 내부 검토하고 수정본을 다시 대조했다. 학회 심사나 새로운 실물·시뮬레이션 실험의 판정은 아니다.

## 판단

핵심 수식의 차원·부호·학습 분모·비용 계수와 기존 표·그림 수치에서 결론을 뒤집는 불일치는 발견하지 못했다. 그러나 **기준선과 선정 절차의 설명 부족, 평가 모집단의 제한, 위치 예측 개선의 해석 범위**는 내용상 수정이 필요했다. 원고의 논리 연결은 다음과 같이 명시했다.

> 인계 자세 정렬을 배경으로 학습 손실의 효과를 묻는다 → S1/SK의 출발 상태와 추가 갱신 수를 통제한다 → 고정 행동의 위치 예측(RQ1), 공통 후보의 실제 비용 손실(RQ2), 자체 정책의 인계 성공(RQ3)을 따로 평가한다 → 위치 예측의 일부 개선을 관찰했지만 선택손실·인계 개선은 확인하지 못했다고 결론 낸다.

세 평가의 상태 분포와 후보 수가 다르므로 이 연결은 분석 구조이며, 같은 예측 오류의 인과 전달이나 통계적 매개 효과를 입증한 연결은 아니다.

## 실제로 다시 확인한 범위

- 상태 10·입력 11·출력 10, 19,338 파라미터, 정규화, yaw 적분, 창 내 한 단계 손실과 전체 상태 자유 예측 손실을 코드와 대조했다.
- 비용 9항, 탐색 속도 0.03m/s와 비용 scale 0.06m/s, 무효 후보 처리, 감독기의 영 명령, 0.5ms 표본 기반 유지 판정을 대조했다.
- 예측 표의 21개 값과 그림의 12개 점은 저장된 family 평균에서 대조했다. 그림 1은 실측 장면·궤적이 아닌 S1/SK 개념도라고 명확히 표시했다.
- E2 96행에서 요약과 bootstrap **163배열**, E1 84진단에서 요약과 bootstrap **379배열**을 정확히 재생성했다. 후보·겹치는 창·seed·반복을 독립 초기조건으로 세지 않았다.
- E1 576회 실제 반복의 상태·명령·비용·유효성 배열을 비교했다. 모든 실제 반복은 유효했고 같은 후보의 세 반복은 동일했다. 예측 1,344개 중 무효 13개와 선택손실의 정의 가능 여부를 구별했다.
- 새 학습·모델 추론·물리 실행은 하지 않았다. 공개하지 않은 고주파 원시와 고정 예측의 전체 창별 배열을 새로 재검증한 것은 아니다.

## 문서 수정으로 해결하지 않은 연구 한계

1. 예측오차가 비용 순위와 인계 실패에 미친 **인과 기여도**는 아직 분리하지 않았다. 같은 실패 직전 상태에서 모델·후보 탐색·비용을 바꾸는 대조가 필요하다.
2. E1의 음의 회전·음의 접선 오프셋, 자체 정책 방문 상태, 온라인 N128 후보군까지 선택 일치 결과를 확대할 수 없다.
3. 유지시간을 직접 반영한 비용이나 미래 감독기를 포함한 예측이 더 좋을지는 미검증이다. 현재 비용의 설계 차이는 확인했지만 실패 원인으로 확정하지 않았다.
4. 신규 blind 평가 집합, 더 많은 초기조건·학습 seed, 형상·물성 변화, 실물·후속 집기·사업 효과는 별도 평가가 필요하다. 작은 연구의 음성 결과를 범용 학습 제어의 우열로 바꾸지 않는다.

학습 목적과 제어 목적의 불일치는 [Lambert 등의 선행 연구](https://proceedings.mlr.press/v120/lambert20a.html)에서 이미 다룬 내용이다. [부품 공급의 공개 사례](https://www.fortvillefeeders.com/dual-three-position-shuttle-for-small-lightweight-parts/)는 작업 배경의 근거이며 학습 모델의 필요성·현장 성능을 입증하지 않는다. 두 자료의 조건과 이번 시뮬레이션을 구별했다.
