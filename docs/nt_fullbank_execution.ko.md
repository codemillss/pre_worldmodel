## 1. 실행 목적과 범위

이번 실행의 질문은 **목표 근처의 같은 상태·같은 후보에서 모델이 예측한 미래와 실제 미래가 어떻게 다른가**다. 원래 정식 비교의 성공률을 교체하거나 다시 학습하는 실행이 아니다. 입력은 translation-03 / S1-11 / tick78에서 D1으로 복원한 N-T 상태 하나다. 원래 tick78에는 내부 전체 snapshot이 없었으므로, 없던 원본 snapshot과 직접 비교했다는 주장을 하지 않는다.

원래 후보 0–127의 128개 명령열을 유지했다. R은 선형 동역학, S1-11/23/47은 한 단계 손실로 학습한 MLP, SK-11/23/47은 같은 구조에 0.1×5단계 자유 예측 손실을 추가한 MLP이며 숫자는 학습 seed다. **7모델의 전체 128후보 예측을 먼저 저장·인증한 뒤**, 공통 실제 환경에서 후보별 A/B를 각 3회 실행하도록 정했다. 실제 미래는 모델마다 중복 실행하지 않는다. 같은 물리 결과를 일곱 예측과 대조하는 설계이므로 예정 실제 궤적은 128×2×3=768개다.

- **A:** 명목 명령 5개를 0.5초간 고정 실행한다. 미래 재계획·정지 감독기 명령 치환 없이 원래 9항 H5 비용을 평가한다.
- **B:** 현재 자세에 따른 영 명령과 추가 관찰 시간을 포함해 최대 0.8초까지 인계 준비를 검사한다. 준비되면 종료한다. 감독기·관찰 시간·종료 관례가 함께 달라지므로 A와의 차이를 정지 감독기 단독 효과라고 해석하지 않는다. B에 H5 비용을 붙이지 않는다.
- 세 실제 반복은 재현 검증이다. 독립 초기조건이나 성공 확률의 표본이 아니다. 새 학습·모델 수정·후보 추가는 없다.

자원·중단 처리 순수 단위검사 12개와 독립 진입 설계 검토가 통과했다. 이는 실행 중 OS 지연이나 반환하지 않는 native 호출의 강제 시간 보장을 뜻하지 않는다. 구간이 반환될 때 협조적으로 검사하고, 반환된 자료를 먼저 남기는 계약이다.

## 4. 왜 중단했는가

후보11/B/첫 반복의 **전체 결과 저장·재읽기·복원·exact 비교 묶음**이 6.159초로 측정됐다. 사전 바닥값 4.114초보다 49.7%, 직전 실행 중 최대 4.945초보다 24.6% 컸다. 해당 전체 저장 묶음은 약 1.04MB다. 집계 시간만 있으므로 그 증가를 쓰기, 읽기, 타입 복원, 비교 중 하나의 탓으로 확정하지 않는다.

| 마지막 예산 구성 | 시간 |
|---|---:|
| 이미 쓴 누적 실행 시간(종료 직전 내부 시계) | 952.65초 |
| 남은 구간 기본 실행·원시 기록·검증 | 3,514.84초 |
| 남은 원본 D2 대조 | 52.93초 |
| 남은 첫 반복 전체 결과 저장·복원 | 2,143.33초 |
| 남은 루프·고정 작업 | 40.34초 |
| 최종 감사·보고 여유 | 600초 |
| **누적 예상** | **7,304.08초 = 121.73분** |

가장 큰 예상 증가분은 새 최대 단가를 남은 232개 첫 반복 그룹에 적용한 데서 발생했다. 저장량 예상은 약 1.02GiB, 디스크 여유는 약 9.46GiB여서 저장·여유 공간 조건은 통과했다. **실제로 2시간을 소모한 것이 아니라 남은 전체 작업의 보수적 예상이 상한을 넘어서 중단**한 것이다. 모델 실패나 물리 무효 판정 때문에 종료한 것도 아니다.

외부 프로세스 측정은 새 실행 290.556초다. 기존 662.505초를 포함한 실행 누적은 **953.062초 = 15.884분**이며, 아래 사후 감사·공개 정리 시간은 별도 기록한다. 실행 전부터 고정한 600초 여유를 임의로 줄이거나 최대 단가를 평균값으로 바꾸지 않았고, 재시작·자동 재시도·원시 자료 덮어쓰기를 하지 않았다.

최종 전달 장부는 사후 분석·독립 감사·공개·보고서 작성과 대기 시간을 겹치지 않게 **663.53초**로 별도 계상했다. 계획 여유600초보다 길었으므로 이 차이도 남긴다. 장부 작성까지 실제 누적은 **1,616.59초(26.94분)**이며, 이후 Git 게시·검증에 120초를 추가 예약한 보수적 합계는 **28.94분**으로 2시간 안이다. 이 사후 측정으로 실행 중의 중단 판정을 소급 변경하지 않는다.

## 5. 이번 자료로 답할 수 있는 것

전체 128후보의 실제 순위, 인계 가능 후보의 부재, 비용과 인계의 충돌 또는 후보 탐색 부족을 확정할 수 없다. 7모델 전체 예측이 있어도 실제 미래 698건이 미실행이기 때문이다. 선행 D2의 실제 행을 이번 768행에 끼워 넣지도 않는다. 새로운 고유 실제 전이 평가 역시 수행하지 않았으므로, 이번 결과에 teacher 평가가 완료됐다고 표시하지 않는다.

저장 분석에서 A의 후보0–11은 모두 세 반복이 일치하고 물리 유효했으며, H5 안 인계 준비 후보는 없었다. B는 후보0–10의 세 반복이 일치했고 후보9가 0.6초에 준비됐다. SK-23은 후보11의 A 미래를 무효로 예측했지만 실제 A는 유효했다. 이는 국소적인 무효 예측 사례이며, 그 후보가 인계에 유리하다거나 원래 폐루프 실패의 원인이라는 결론은 아니다. 이 범위는 기존 D2에서도 관찰한 후보이며 새 상태·새 후보의 발견으로 제시하지 않는다.

모든 모델이 선택한 후보의 이번 실제 미래가 없으므로 선택 손실을 계산하지 않는다. 관측한 A 후보12개 중 최저 비용은 후보8의 6.676132지만 전체128의 최저 비용은 미확인이다. 이 비용을 인계 성공 점수로 읽으면 안 된다. 비용–인계 충돌 가설 C와 후보 탐색 가설 S는 보류다.

완료한 부분은 **실행기와 보존·검증 계약이 실제 데이터에서 작동하고, 예상 최대 비용이 커질 때 새 물리를 중단했다**는 증거다. 아래 저장 자료 분석은 관측 부분집합의 판정이며 전체 후보 결론과 구분한다. 특히 현재 자료는 앞선 D2에서 이미 실행한 후보 범위 안에 있어 새 후보 범위의 과학적 결론이 늘었다고 제시하지 않는다.

다음 본 실행 전에 확인할 것은 **같은 전체 필드와 exact 비교를 유지하면서 전체 결과 보존 묶음의 비용을 더 잘 분해·예측할 수 있는가**다. 저장 형식이나 처리 방식을 바꾼다면 별도 버전의 작은 동일 입력 대조에서 저장 내용·중첩 타입·StepResult·복원 exact 수준이 그대로인지 먼저 확인해야 한다. 현재 중단 실행을 성공으로 바꾸거나 예산 조건을 소급 수정하지 않는다.
