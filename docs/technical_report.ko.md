# 예측 개선은 인계 성공을 개선하는가

부품 밀기 정렬의 학습 동역학·행동 선택·폐루프 결과 비교

기술 보고서 · 2026-10-22 · 사후 종합본 · 리뷰 반영본

## 초록

부품 공급 셀에서 다음 작업에 넘길 자세를 만드는 상황을 배경으로, 학습한 미래 예측의 개선이 행동 선택과 실제 인계 성공으로 이어지는지 평가했다. 고정 형상의 직사각형 부품과 XY 푸셔를 사용한 MuJoCo 시뮬레이션에서 기하 피드백 G, 선형 동역학 R, 한 단계 학습 S1, 다단계 자유 예측 손실을 추가한 SK를 비교했다. 12개 독립 초기조건에서 총 96개 폐루프 실행을 기록하고, 별도의 고정 상태·후보 진단에서 576회 실제 미래를 실행했다. G/R/S1/SK의 성공은 각각 8/12, 0/12, 13/36, 12/36이었다. S1·SK의 36회는 12개 초기조건과 학습 seed 3개의 조합이다. 일부 seed에서 SK의 고정 행동 K5·K10 위치 예측오차는 작았으나, 후보 선택손실과 인계 성공 개선은 확인되지 않았다. 본 결과의 기여는 새 알고리즘이나 산업 효과의 입증이 아니라, 예측·선택·작업의 연결을 분리해 검증하고 부정 결과와 재현 근거를 남긴 데 있다.

## 1. 문제와 연구 질문

수평 작업대 위 어긋난 부품을 옆에서 밀어 지정 위치·방향으로 맞춘다. 잠재 사용자는 부품 공급·취급 셀의 정렬 방식을 검토하는 자동화 엔지니어다. 부품의 자세를 유지해 공급할 필요는 공개 사례로 확인되지만, 이번 밀기 정렬 모듈에 대한 고객 수요는 가설이다. 인계 후 집기·삽입은 실행하지 않았다.

Fortville Feeders의 공개 사례는 작은 플런저를 로봇이 집도록 방향과 위치를 유지하는 과제를 전용 툴링·트랙·셔틀로 해결했다. 이 사례는 작업의 의미와 기계식 대안을 뒷받침하며 학습 모델의 필요성을 입증하지 않는다 [1]. 별도 정렬 없이 현재 자세에서 직접 집기, 지그·피더, 기하 피드백도 타당한 대안이다.

Yu 등의 실물 평면 밀기 연구는 형상·표면·속도 등 여러 조건을 바꿔 마찰과 모델 가정을 분석했다 [2]. Bauza 등의 연구는 학습한 GP 동역학을 MPC에 연결했다 [3]. 이번 구성은 해당 논문의 직접 재현이 아니며, 학습 동역학과 계획의 결합 자체를 새 기여로 주장하지 않는다. 기존 접근을 작은 자원에서 구현하고 학습 손실의 제한된 효과를 비교하는 기술 검증이다.

예측 학습과 제어 성과의 목적 불일치는 선행 연구에서 다뤘다 [4]. 예측을 다시 입력할 때의 분포 변화와 다단계 학습도 알려진 연구 주제다 [5]. 본 실험의 기여는 그 현상의 최초 발견이 아니라 고정한 학습 절차·과제의 제한된 실증 비교다.

주된 비교는 S1과 SK의 손실 개입이다. RQ1은 같은 실제 상태·행동에서 위치 예측오차와 무효 수의 차이, RQ2는 같은 후보의 실제 비용 선택손실 차이, RQ3는 자체 정책의 인계 성공 차이다. 고정 행동 예측·E1·E2가 각각 답한다. 학습 모델을 구현하는 것은 선정 목표이며, 그 모델이 더 좋다는 결론은 실험 대상이다. [정형 학술 원고](../paper/main.tex)는 같은 결과의 수식·방법을 상세히 기술한다.

## 3. 시스템과 입출력 계약

현재 관측 → 후보 명령열 → 학습 모델의 미래 예측 → 비용과 유효성 비교 → 첫 명령 실행 → 새 관측의 순서로 작동한다. 모델이 학습하는 것은 행동 조건부 상태 변화다. 후보 생성·최소 비용 선택·속도 제어·접촉 물리·인계 판정을 모두 학습한 정책은 아니다.

| 경계 | 표현 | 의미 |
|---|---|---|
| 관측 s | 10차원 | 부품 x,y,yaw,vx,vy,wz와 푸셔 x,y,vx,vy |
| 명령 u | 2차원 | world XY 목표 속도, 0.1초 유지 |
| 모델 입력 phi(s,u) | 11차원 | 상대 XY, sin(2yaw),cos(2yaw), 부품 속도3, 푸셔 속도2, 명령2 |
| 모델 출력 | 10차원 | 다음 0.1초 전체 상태 증분의 정규화 예측 |

위치·각도·속도 단위는 m·rad·m/s·rad/s다. 목표 속도와 실제 푸셔 속도는 다를 수 있다. 푸셔의 미래 상태도 모델 출력에 포함하며 명령×시간으로 대체하지 않는다. 정규화는 train 통계로 고정한다. 목표 자세는 동역학 입력이 아니라 계획 비용에 사용한다.

MLP는 11→128→128→10, SiLU 활성화와 선형 출력이다. 네트워크는 float32, 물리 경계는 float64다. 예측 증분을 역정규화해 현재 상태에 더하고, 이후에는 예측한 전체 상태를 다시 입력한다. yaw 전이 잔차의 2π wrap과 직사각형 작업 방향의 π 대칭을 구분한다. 이 상태 표현이 숨은 접촉 상태의 충분통계임을 증명하지는 않았다.

온라인에서는 128개 후보를 H5, 즉 0.5초까지 예측해 원래 9항 가중 비용으로 평가한다. 첫 0.1초만 실행한 뒤 재관측한다. 영 명령·이전 최적열·기하 제안과 난수 후보를 사용하는 shooting 방식이다. 공통 규칙을 사용해도 서로 다른 폐루프 상태와 warm start 때문에 매 시점 후보 배열까지 같지는 않다.

실제 속도 추종과 접촉 적분은 기존 제어기·MuJoCo가 담당한다. 실제 위치·방향이 목표 범위 안이면 공통 감독기가 영 명령을 적용해 정지·유지를 검사한다. 인계 성공은 계획과 이 규칙의 결합 결과다. 학습 계획 중 실제 미래 물리를 조회하지 않는다. E1에서 후보의 실제 미래를 실행하는 것은 선택 이후의 오프라인 진단이며 온라인 oracle이 아니다.

9항 비용은 위치·방향·명령 크기·명령 변화·푸셔 간격의 다섯 단계 항과, 마지막 위치·방향·선속도·각속도 네 항이다. 0.3초 유지시간이나 미래 목표 진입 시 감독기 전환은 명시적으로 최적화하지 않는다. 비용 선택손실과 실제 인계 성공은 서로 다른 보고량이다.

## 4. 비교 방법과 학습 개입

| 방법 | 미래 예측 | 행동 생성과 비교 의미 |
|---|---|---|
| G | 학습 예측 없음 | 조정된 기하 피드백. 전체 제어 구성의 기준선 |
| R | 선형 증분 모델 | 공통 계획기에서 단순 예측 기준선 |
| S1 | MLP 한 단계 학습 | 같은 실제 전이 창의 한 단계 오차 학습 |
| SK | MLP 한 단계+자유 예측 학습 | S1과 통제한 출발점에서 다단계 항의 효과 |

R은 Ridge 계열에서 α=0이 선택됐으므로 최종 예측기는 무정규화 선형 회귀다. R·S1·SK는 공통 계획기를 공유한다. G와 학습 계획기의 차이에는 제어 구조도 포함되므로 그 차이를 모두 신경망의 인과 효과로 해석하지 않는다.

G는 후퇴·접선 이동·접근·밀기의 상태기계다. yaw·각속도에 따라 뒤쪽 접촉 오프셋을 조정하고 현재 형상 경로 검사와 전환 완화를 사용한다. R은 같은 11차원 특징의 정규화 잔차 제곱합에 적합하며, 절편은 벌점에서 제외하고 α 후보 8개를 validation K5로 선정했다. G의 위치 이득과 N128/H5 계획은 이전 개발 3조건의 5초 대리 평가에서 정했다. 각 수식과 선정 범위는 학술 원고와 공개 설정에 제공한다.

seed 11·23·47마다 S1/SK는 공통 가중치·Adam 상태·RNG·정규화·자료·배치 순서에서 출발해 각각 1,000 update를 추가했다. S1의 한 단계 항은 K5 창의 실제 전이들을 사용한다. SK는 초기 실제 상태에서 출발한 자유 예측의 K1~K5 상태 오차를 추가한다. 유효 전이와 출력 10차원에 따른 분모를 고정하고 종료 뒤 padding은 제외한다.

`L_S1 = L_one`이고 `L_SK = L_one + 0.1 × L_rollout`이다. λ는 validation에서 선정했다. 두 군은 같은 update 수를 사용하지만 SK는 forward가 추가되므로 같은 FLOPs·시간 예산으로 해석하지 않는다.

같은 갱신 수가 목적별 수렴 정도를 맞추는 것은 아니다. 추가 항이 기울기 크기·clipping·Adam 경로에 주는 변화와 다단계 예측 오차를 학습하는 효과를 분리하지 않았다. 결론은 이 출발점·선정 가중치·학습률·1,000회 추가 갱신 절차에 한정한다. 선정의 수치·yaw 유효성과 최종 예측·계획의 작업공간·침투 검사는 다르다.

최종 비교는 P4-02 update1000 체크포인트와 원래 H5 비용을 사용했다. 이후 D11 자료 보완, R1 상대위치 학습항, 인계 우선 H10 비용은 개발 진단이며 최종 모델·비용으로 승격하지 않았다. 개발 진단의 결과를 최종 정책의 원인 증명으로 섞지 않는다.

## 5. 실험과 판정 규약

목표 자세는 [0.08m, 0, 0]이다. 성공 ready는 위치 오차 5mm 이하, 방향 오차 3° 이하, 선속도 0.01m/s 이하, 각속도 0.05rad/s 이하를 실제 물리 관측에서 연속 0.3초 유지한 경우다. 최대 30초·작업 재시도 0회, 물리 간격은 0.5ms다. 이 문턱은 산업 공차가 아닌 실험 명세다.

| 평가 | 고정·실행 내용 | 독립성·해석 |
|---|---|---|
| 고정 행동 예측 | G의 12개 실제 경로, K1/K5/K10 재귀 예측 | 독립 family 12. 겹치는 창은 독립 표본 아님 |
| E1 후보 선택 | G의 초기·2.9초 12상태×16후보×3실행=576회 | 독립 family 6. 7모델이 실제 라벨 공유 |
| E2 인계 작업 | 병진·회전·오프셋 각4조건×8방법=96회 | 독립 family 12. 신경망은 3seed |
| E3 학습 손실 | E1/E2의 S1·SK 비교 | 새 물리 실행 수를 더하지 않음 |
| 실제 제어 재현 | 사전 선정 규칙의 33사례 재실행 | 저장 수치 재집계와 별도 증거 |
| 작은 적용 | 같은 범위의 예약 13번째 family×8방법 | E2와 합치지 않음. 새 태스크·OOD 아님 |

성공 비율 차이는 family 내부 seed를 먼저 평균하고 층 내 family bootstrap 2,000회, seed 7711의 95% percentile 구간으로 나타냈다. 여러 탐색적 비교의 다중비교 보정은 하지 않았다. 0을 포함한 구간은 동등성 증거가 아니다.

이는 고정한 학습 seed와 초기조건 설계 범위의 재표집 구간이며 학습 seed 모집단이나 산업 발생률 전체의 불확실성을 포함하지 않는다.

E1 선택손실은 선택 후보의 실제 평균 비용에서, 세 반복 모두 유효한 후보 중 최소 실제 평균 비용을 뺀 값이다. 유한 후보군에 대한 후회 비용이며 전역 최적 제어와의 차이가 아니다. 반복 비용 범위가 겹치는 순위는 INCONCLUSIVE로 남긴다. 해당 범위는 신뢰구간이 아니다.

순위 비교는 실제 반복 범위 양쪽에 ε=10⁻⁶+10⁻⁵×후보 반복비용 절댓값 최댓값을 더한다. 세 실제 반복은 같은 후보의 상태·명령·비용이 동일했으므로 물리 잡음의 분산 추정이 아니라 결정론적 재현 검사다. E1의 회전·오프셋 층은 양의 초기 회전·접선 오프셋만 포함하고, 시작 위치오차는 56.067–93.612mm, 실제 후보 끝점 최소 오차는 49.462mm였다. 종단 5mm 정렬·정지·유지를 직접 표집하지 않았다.

첫 정식 실행은 R 제어 후 저장 과정에서 중단됐다. 첫 실행·부분 원시는 보존하고 저장기만 보완해 같은 과학 조건으로 실행02를 새로 시작했다. 초기조건은 복구 전에 결과 일부를 알게 된 조건이므로 새로 뽑은 미공개 시험이라고 하지 않는다. 부모 결과를 합치거나 유리한 결과를 골라 교체하지 않았다. 집계 순서의 미세 부동소수 차이도 원본을 보존한 별도 분석에서 순서를 고정해 해결했다.

## 7. 관찰된 차이와 남은 원인 가설

서로 다른 평가에서 일부 위치 예측 개선, 드문 선택 차이, 인계 개선 미확인을 각각 관찰했다. 어느 연결이 병목인지는 확정하지 않았다. 평균 예측오차 → 후보별 비용·순위 → 선택 행동 → 실제 접촉 → 연속 인계 판정은 분석할 연결이며, 같은 개별 예측을 따라가 인과적으로 식별한 연결은 아니다.

### 7.1 확인된 사실

고정 행동 예측은 G가 방문한 상태와 행동에서 측정했다. E2는 각 모델이 스스로 선택한 행동으로 상태를 바꾼다. 평가 분포가 구조적으로 다르므로 고정 경로 예측 개선만으로 자체 정책의 미래 정확도를 보장할 수 없다. 분포 차이가 실제 실패를 얼마나 설명하는지는 아직 측정하지 않았다.

E1에서 S1/SK 동일 seed·snapshot 36쌍 중 35쌍은 같은 후보 번호를 골랐다. 유일한 차이는 translation-00, G tick29, seed47로 S1은 후보2·선택손실0, SK는 후보6·손실0.235521이었다. 이는 초기 접근 N16/H5 후보군의 드문 선택 차이이며 온라인 N128 전체 정책의 동일성은 아니다. E2의 유일한 성공 차이는 translation-03·seed23이므로 이 E1 사례로 설명할 수 없다.

실패 63개 중 종료 순간 위치 미충족은 62개, 방향은 38개, 각속도는 2개, 선속도는 0개였다. 조건별 수는 중복된다. 대부분을 단순한 정지 속도 문제라고 설명할 근거는 없다. G rotation-02는 마지막 네 순간 조건을 만족했지만 유지 시간이 0.0825초라 0.3초 기준을 충족하지 못했다. 정지 화면과 인계 완료는 다르다.

## 8. 개발 과정에서 실제로 좁힌 설명

문제 정의 후 환경·입출력·접촉 물리를 먼저 검사하고, 자료 분할·정규화·기준선·공통 신경망을 준비했다. 이후 S1/SK 분기를 비교하고, 실제 실패에서 비용·접촉·정지 자료·학습항·갱신 방향의 가설을 순차적으로 좁혔다. 마지막에 원래 모델과 설정을 동결해 정식 비교했다. 아래 개발 결과는 최종 H5 정책의 인과 결론과 구분한다.

인계 비용을 검토한 한 개발 상태의 H10에서는 실제 인계한 후보11의 기존 비용9.586888이 인계하지 못한 후보60의8.804576보다 높았다. 비용과 작업 목적의 불일치가 존재하는 구체적 사례다. 인계 우선 비용으로 실제 후보11을 선호하도록 바꿔도, 모델이 후보77을 성공처럼 예측하는 오류는 남았다. 비용만 바꾸면 모델 오류까지 해결된다는 설명은 지지되지 않았다.

후보77의 실제 1초 실행에서는 옆면 접촉 진입이 없고 부품이 정지했다. 실제 상태를 다시 입력한 첫0.1초에서도 부품 오차0.365~0.414mm가 남아 재귀 누적만으로 설명할 수 없었다. 이는 개발 source99·seed11·선정 후보에 한정한다.

## 9. 한계와 해석

고정 형상·물성, 시뮬레이터 현재 상태 직접 관측, 제한된 초기 범위·접촉면, 작은 표본에 한정한다. 관측 노이즈·지연, 다품종·마찰 변화, 카메라, 일반 접촉면 전환, 실물 로봇과 후속 집기는 평가하지 않았다. 숨은 물리 상태에 대한 관측 표현의 충분성도 미확인이다.

R은 선형 모델의 기준선이며 분석적 밀기 모델·GP·불확실성 기반 계획 전체를 대표하지 않는다. 실제 동역학을 사용한 폐루프 계획 대조도 수행하지 않아 모델과 탐색·비용의 한계를 분리하지 못했다. 학습 목적의 충분한 수렴을 입증하지 않았으며, 후반 D11/R1 최적화 진단도 최종 분기의 수렴 근거가 아니다.

같은 초기조건의 세 학습 seed 실행을 추가적인 독립 초기조건으로 세지 않았다. 겹치는 예측 창·후보·물리 반복·검산 항목 수로 독립 표본 수를 늘리지 않았다. 예측 무효·계획 실패·timeout은 각각 원래 분모에 남겼다. 성공한 조건만의 평균 시간으로 전체 공정 시간 단축을 주장하지 않는다.

원래 결과·실패·중단을 보존했다. 복구는 같은 과학 조건의 실행 재시작이며 완전히 새로운 blind test는 아니다. 공개 저장소는 선별된 재현 묶음이다. 로컬 원시 전체·시스템 환경·모든 과거 진단까지 업로드했다는 뜻은 아니다. 공개본에서 확인할 수 있는 범위는 [근거·재현 색인](../artifacts/index.md)에 명시한다.

## 10. 결론

학습 동역학을 구현하고 재귀 예측으로 행동을 선택하며 실제 인계 준비 조건까지 검사하는 목표는 달성했다. 일부 고정 행동의 위치 예측 개선은 확인했지만 SK의 후보 선택과 인계 개선은 확인하지 못했다. 이 결과는 학습 기반 계획 전체의 부정도, 방법 간 동등성의 증명도 아니다. 세 평가의 관찰과 실패를 보존했으며 종단 병목의 인과 규명은 남은 과제다.

사용자는 문제 가치와 학습 목표, 비교 기준, 진행·보류 판단을 논의하고 선택했다. Codex는 코드·학습·반복 실행·검산·시각화·문서 작성을 수행했다. 코드량이나 자동 검사 완료를 개인 역량의 대리 지표로 삼지 않는다. 다음 면접에서는 입력 계약·S1/SK 손실 차이·35/36 선택 일치의 해석·실패를 배제하지 않은 이유를 직접 설명할 수 있는지 별도로 확인할 수 있다.

## 부록 B. 재현 단계와 문서 운영

Markdown은 수정·차이 검토·GitHub 탐색용 원본이고 PDF는 같은 원고에서 만든 읽기·제출용 결과다. 핵심 목표표·수치·실패·가설은 PDF 본문과 부록에 직접 수록했다. 별도 MD를 열지 않아도 결론과 한계를 이해할 수 있다. 세부 수치·코드·가중치는 저장소의 상대 링크로 연결하며, 내려받은 PDF의 링크는 공개 저장소 주소로 연결한다.

공개 자료의 SHA와 수치 확인 → 실제 모델 로드·1/5단계 예측 → 필요시 작은 물리 실행 순으로 검토한다. 전체 원시를 전제로 하는 기존 최종 실행·독립 감사 명령은 공개본만으로 완전 재생된다고 보장하지 않는다. 정확한 실행 명령·설치 환경·포함 및 생략 파일은 [근거·재현 색인](../artifacts/index.md)에 있다. 원래 28단계 완료 판정과 이번 공개본의 설치·문서 검증을 구분한다.
