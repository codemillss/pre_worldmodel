# 리뷰어 관점 평가: 예측·선택·인계 실험

2026-10-22 · 내부 문서·근거 검토 · 검토 출발 커밋 2fb3447

논문, 설명용 기술 보고서, 사업 보고서, README를 같은 주장 범위로 검토했다. 로봇 조작·학습 동역학·실험 설계의 관점으로 문제, 선행 연구, 방법, 결과, 기여를 비판적으로 읽었다. 외부 학회 심사나 전문가 자격 인증의 결과는 아니며, 새 학습·모델 추론·물리 실행은 하지 않았다.

## 1. 총평과 주장 가능한 기여

**고정 조건의 S1–SK 비교와 그 관측 결과는 유지할 수 있다. 그러나 최종 인계 실패의 병목을 인과적으로 설명하거나 일반적인 학습 기반 계획의 효용을 판단하는 연구로 읽히면 근거가 부족하다.**

강점은 공통 가중치·Adam 상태·자료·배치 순서에서 학습을 분기하고, 고정 행동 예측·실제 후보 비용·폐루프 성공을 구분하며, 무효·실패·저장 중단까지 근거에 남겼다는 점이다. 작은 신경망과 제한된 자원으로 예측이 행동에 사용되는 실행 구조를 만들었다는 구현 기여도 분명하다.

다만 예측 정확도와 제어 성과의 차이는 이미 알려진 연구 주제다. 새 알고리즘·일반적 메커니즘·현업 효과를 기여로 내세울 근거는 없다. 현재 문서는 **감사 가능한 제한 조건의 학습 기반 계획 사례 연구**로 읽는 것이 타당하다. 더 강한 연구 기여를 주장하려면 아래의 실험 보강이 필요하다. 문장 수정만으로 그 근거가 생기지는 않는다.

## 2. 주요 지적

### R1. 후보 선택 진단은 마지막 정렬·유지 구간을 검사하지 않았다

중요도: 높음. 문서 설명은 수정했고, 종단 병목 규명에는 추가 실험이 필요하다.

E1은 G 경로의 제어 시작과 2.9초에서 추출한 12개 상태다. 공개 실제 미래 배열을 검산하면 시작 위치오차는 **56.066898–93.612083mm**, 전체 후보의 실제 끝점 최소 오차는 **49.462125mm**다. 5mm 안의 저장 끝점·행동 경계 상태는 없다. 회전·접촉 오프셋의 초기 부호도 양의 방향만 포함한다.

따라서 E1은 접근 중 후보 비용 순위를 검사한다. S1/SK 35/36쌍의 선택 일치는 이 범위에서 선택 차이가 드물다는 근거이며 마지막 5mm 정렬·정지·유지의 병목을 식별한 근거는 아니다. 온라인 N128의 자체 정책과 E1 N16의 G 상태도 같지 않다.

근거: [초기조건·snapshot 선정](../src/push_align/final_manifest.py), [E1 실제 미래 배열](../artifacts/results/E1/snapshots/). 원고의 방법·논의, 두 보고서와 README에 범위를 추가했다.

### R2. 성공률 차이는 단 한 seed–초기조건 쌍에서 생겼다

중요도: 높음. 추가 물리 없이 저장 결과로 확인하고 반영했다.

E2의 S1/SK를 같은 초기조건·학습 seed로 짝지으면 **동시 성공12, 동시 실패23, S1만 성공1, SK만 성공0**이다. 유일한 불일치는 **translation-03·seed23: S1 ready / SK timeout**이다. −2.78%p를 여러 조건에 걸친 일관된 악화로 읽지 않아야 한다.

E1의 유일한 선택 차이는 translation-00·tick29·seed47로 다른 사례다. E1의 선택 일치35/36과 E2의 성공 여부 일치35/36은 우연히 숫자가 같을 뿐 별도 관측이며, 앞의 사례가 뒤의 차이를 설명하지 않는다. 36쌍은 12개 독립 초기조건과 고정한 세 학습 seed의 조합이다.

근거: [E2 96행](../artifacts/results/E2/rows.json), [E1 선택 분석](../artifacts/audits/p5_final_E1_choice_agreement.v1.json). 원고·두 보고서·README에 짝별 결과와 차이의 규모를 반영했다.

### R3. 같은 갱신 수는 학습 목적의 충분한 최적화를 뜻하지 않는다

중요도: 높음. 한계는 명시했으며 수렴·최적 예산을 주장하려면 근거 보강이 필요하다.

같은 출발점과 1,000회 갱신은 절차의 통제다. SK 항은 기울기 크기·방향, clipping과 Adam의 경로에도 영향을 줄 수 있다. 전체 10차원 다단계 목적의 수렴을 보여주는 결과는 본문에서 제시하지 않았다. 일부 XY 예측 개선만으로 수렴을 대신할 수 없다.

따라서 결론은 해당 가중치 선정·학습률·추가 갱신 예산의 두 절차에 한정한다. 다단계 예측 오차를 학습하는 효과와 최적화 경로의 효과는 분리되지 않았다. D11/R1의 후반 Adam 진단은 최종 P4-02 분기의 수렴 증거가 아니다. 저장 학습 로그를 별도 분석하면 보강할 수 있지만 이번 검토에서 새 학습이나 수렴 확인을 한 것은 아니다.

근거: [분기 예산](../configs/p4_fork_budget.v2.json), [시퀀스 학습](../src/push_align/sequence_training.py), [개발 경과](../artifacts/development/index.md). 원고·기술/사업 보고서·README의 해석 범위를 좁혔다.

### R4. 모델 오류와 비용·탐색 제약의 기여가 분리되지 않았다

중요도: 높음. 현재의 좁은 비교 결론은 유지되나 메커니즘 설명에는 실험이 필요하다.

R은 같은 특징 위의 선형 모델이다. 분석적 밀기 모델·GP·불확실성 기반 학습 계획 전체를 대표하지 않는다. 모든 유명 기법을 추가할 필요는 없지만 R보다 좋은 결과를 넓은 방법 우위로 설명해서는 안 된다.

현재 비용은 끝점 속도를 포함하지만 유지시간·이산 성공·미래 감독기 전환은 직접 최적화하지 않는다. E1의 실제 비용 최선은 인계 성공 최선과 다르다. 실패 상태의 공통 후보를 실제 물리로 대조하거나, 실제 동역학을 사용하는 계획기를 폐루프로 검사하지 않았으므로 모델·비용·탐색 중 어느 요소가 최종 실패를 주도했는지 분리하지 못했다.

근거: [비용과 후보 계획](../src/push_align/planning.py), [공통 감독기 실행](../src/push_align/final_execution.py). 문서의 “개선이 전달되지 않은 지점을 확인했다”는 표현을 “서로 다른 평가의 관측이며 병목은 미확정”으로 수정했다.

### R5. 작은 평균 위치오차 변화와 작업 효과를 구분해야 한다

중요도: 중간. 보고된 수치를 유지하고 성분·모집단·실용적 의미를 제한했다.

seed23 K5 평균 위치오차는 0.090605→0.058647mm다. 차이는 5mm 작업 문턱보다 작지만 이 사실만으로 무해하다고 결론 낼 수 없다. G 고정 행동의 평균이며 자체 정책의 목표 근처 꼬리 오차·접촉 유효성·비용 순위 민감도를 측정한 값이 아니기 때문이다.

seed47은 같은 위치 지표가 좋아지면서 yaw·각속도 오차는 소폭 커졌다. seed11과 R은 예측 무효 mask도 다르다. 모든 모델을 표에 유지하고 공통 유효 창을 비교할 수 있는 seed23·47의 기술 통계라는 점을 명시한다. 학습 seed 전체의 평균적 우위나 모든 상태 성분의 개선으로 확대하지 않는다.

근거: [고정 행동 예측 결과](../artifacts/results/fixed_prediction/summary.json), [그림의 실제 수치](../paper/figures/fixed_prediction.values.json).

## 3. 가장 먼저 보강할 실험 하나

**개발 조건의 목표 공차 근처 또는 실패 직전 상태에서, 같은 후보군의 모델 예측과 실제 미래를 대조한다.** 이번 문서 검토에서는 실행하지 않았다.

상태를 정할 때는 부품·푸셔 상태10만이 아니라 시뮬레이터 전체 snapshot, 제어·감독기 상태, 직전 명령과 계획 문맥까지 고정해야 한다. 결과를 보고 유리한 후보만 남기지 않고 무효 판정도 함께 기록한다.

확인할 것은 “모델이 실제로 유효하고 낮은 비용인 후보를 거절했는가”, “실제 비용이 낮은 후보도 인계 준비 조건에는 부적합한가”, “후보군 자체가 접근·복구 행동을 포함하는가”다. 실제로 유효한 후보가 예측에서 거절되면 모델·유효성 경계의 가설을 좁힐 수 있다. 실제 비용 순위와 준비 조건이 어긋나면 비용 목적을 재검토할 이유가 생긴다. 제한된 한 후보군의 실패로 태스크 전체가 불가능하다고 판단할 수는 없다.

실제 미래를 쓰는 oracle 진단은 개발 분석 도구이며 배포 가능한 제어기가 아니다. 한 번의 후보 대조는 전체 폐루프의 성능 상한이나 단일 원인을 입증하지 않는다. 보완 결과는 새 개발 실험으로 등록하고 기존 동결 비교·분모를 교체하지 않는다.

**설계 보완(2026-10-22):** [보완 실험 v1](near_goal_diagnostic_design.ko.md)에 6상태·같은 128후보·7모델의 검사와 판정 규칙을 등록했다. 고정 H5 명령/비용 대조와 감독기·추가 정지 대조를 구별하고, ready 후 계속 실행한 결과와 즉시 종료한 결과의 차이도 따로 기록한다. 기본 후보의 누락·반복 불안정이 있으면 후보 커버리지 원인을 확정하지 않는다. 이는 설계의 보강이며 R1/R4의 실험적 해소가 아니다. 새 미래 실행·모델 추론·학습은 미실행이다.

## 4. 선행 연구와 프로젝트 위치

- [Bauza 등, CoRL 2018](https://proceedings.mlr.press/v87/bauza18a.html): GP 동역학과 MPC의 부품 밀기 제어. 학습 모델과 계획의 결합 자체는 신규성이 아니다.
- [Venkatraman 등, AAAI 2015](https://ojs.aaai.org/index.php/AAAI/article/view/9590): 자기 예측을 다음 입력으로 사용하는 다단계 분포 변화와 DaD 방법. 본 K5 손실의 직접 재현이나 이론 보장 근거는 아니다.
- [Lambert 등, L4DC 2020](https://proceedings.mlr.press/v120/lambert20a.html): 예측 학습과 제어 목적의 불일치. 이 일반 현상을 처음 발견한 연구로 내세우지 않는다.
- [Chua 등, NeurIPS 2018](https://proceedings.neurips.cc/paper_files/paper/2018/hash/3de568f8597b94bda53149c7d7f5958c-Abstract.html): 확률적 모델과 불확실성 전파의 PETS. 이번 결정론적 MLP에 해당 구성이 구현됐다는 뜻은 아니다.

이 프로젝트의 문제 가치는 큰 모델을 사용했다는 데 있지 않고, 실제 작업으로 정의한 준비 판정 앞에서 예측 점수·후보 비용·실행 결과를 나누어 검증했다는 데 있다. 다만 그 평가를 나열한 것과 실패 메커니즘까지 규명한 것은 구분해야 한다.
