# 부품 인계 정렬: 학습 기반 계획의 적용 판단 보고서

2026-10-18 · 사업·개발 의사결정용 · 고정 조건 시뮬레이션 기술 검증

## 1. 판단 요약과 문제의 의미

어긋난 부품을 밀어 다음 공정의 인계 자세로 맞추는 과제에서, 학습한 미래 예측이 행동 선택과 작업 성공에 어떤 차이를 만드는지 검증했다. **실험·보고 절차는 완료했으나, 다단계 예측 학습을 추가한 방법의 인계 성공 개선은 확인하지 못했다.** 예측 오차 감소를 현장 성과로 설명하지 않는다.

잠재 사용자는 부품 공급·취급 셀의 정렬 방식을 검토하는 자동화 엔지니어다. 다음 집기·투입 자세로 보정할 수 있는지 판단해야 한다. 단일 직사각형 부품을 옆에서 미는 상황을 선택했다. 별도 정렬 단계가 실제 공정에 이득인지는 아직 확인하지 않았다.

부품을 일정한 자세로 공급하는 작업에는 공개 사례가 있다. Fortville Feeders는 소형 부품을 툴링·트랙·셔틀로 정렬해 로봇에 공급했다. 작업의 필요와 기계식 대안의 개별 사례이며, 학습 모델의 필요성·수요를 입증하지 않는다. [공급업체의 공개 사례](https://www.fortvillefeeders.com/dual-three-position-shuttle-for-small-lightweight-parts/)

현장 대안은 전용 지그·피더, 현재 자세에서 직접 집은 뒤 보정하는 방식, 기하 피드백 밀기, 단순 동역학 계획이다. 학습 동역학을 선택한 이유는 접촉 반응을 데이터로 표현하고 행동 생성에 연결하는 핵심을 검증하려는 목적이다. 기준선이 성공해도 학습 목적은 유지하되, 성능 우위는 별도로 검증한다.

## 2. 구현 범위와 성공 기준

모델은 현재 물체·푸셔 상태와 속도 명령으로 다음 상태의 변화를 학습하고, 예측한 전체 상태를 재입력해 미래를 이어간다. 계획기는 128개 후보의 0.5초 미래 비용을 비교해 첫 0.1초 명령만 실행한 뒤 재관측한다. 계획 중 실제 미래 물리를 조회하지 않는다. 속도 추종·접촉은 기존 제어기와 시뮬레이터가, 목표 자세 안의 영 명령과 정지·유지 판정은 공통 감독기가 맡는다.

비교는 기하 피드백 G, 선형 예측 R, 한 단계 학습 신경망 S1, 한 단계 손실에 5단계 자유 예측 손실을 더한 SK다. R·S1·SK의 계획 조건을 맞췄다. S1·SK는 출발 상태·데이터·갱신 수를 맞췄으나 연산량까지 같지는 않다. G는 행동 선택 구조가 달라 그 차이를 모두 학습 모델의 효과로 읽지 않는다.

인계 성공은 위치 오차 5mm, 방향 오차 3°, 선속도 0.01m/s, 각속도 0.05rad/s 이하를 **연속 0.3초** 유지한 상태다. 최대 30초, 자동 재시도는 없다. 이는 후속 공정 조건으로 가정한 실험 명세이며 산업 공차가 아니다. 목표 통과나 정지 화면은 성공을 대신하지 않는다. 카메라 인식·실물·후속 집기·삽입은 제외했다.

## 3. 최초 목표의 달성 수준

| 최초 목표 | 최종 근거 | 달성 범위 |
|---|---|---|
| 학습 예측을 행동에 연결 | 예측·후보 선택·접촉 실행 구현 | 구현·검증 완료 |
| 기준선·학습 방법 비교 | G·R·S1·SK 96건 | 제한 조건에서 완료 |
| 다단계 학습 효과 확인 | 예측·선택·인계 분리 비교 | 인계 개선 미확인 |
| 인계 작업 수행 | G·S1·SK 성공 사례 | 사례 입증; 안정적 성과 미입증 |
| 실패 이유 구별 | 판정·종료·후보 선택 분석 | 관찰 완료; 원인 귀속 부분적 |
| 작은 새 조건에 적용 | 예약 조건 1개에 8개 방법 | 같은 범위; 일반화 미입증 |
| 근거 보존·재현 | 실제 제어 재현 33건 | 실행·보고 절차 완료 |

실험·보고 28개 항목 완료와 성능 개선·원인 규명·현장 적용은 다르다. 성공률 목표와 최소 의미 개선 폭은 사전 미지정이므로 성능 목표 달성을 선언하지 않는다. 개인의 설계·검증 역량도 산출물 존재만으로 평가하지 않았다.

## 4. 의사결정에 사용할 결과

| 방법 | 인계 성공 | 독립 초기조건 | 학습 seed |
|---|---|---|---|
| G: 기하 피드백 | 8/12 | 12 | 해당 없음 |
| R: 선형 예측 | 0/12 | 12 | 해당 없음 |
| S1: 한 단계 학습 | 13/36 | 12 | 3 |
| SK: 다단계 학습 | 12/36 | 12 | 3 |

S1·SK의 36회는 초기조건 12개에 seed 3개를 적용한 결과이며 독립 조건 36개가 아니다. 시간 초과와 계획·제어 불가도 분모에 남겼다. 초기조건 안에서 seed를 평균한 짝비교의 SK−S1 성공 비율 차이는 −2.78%p, 95% bootstrap 구간은 [−8.33, 0.00]%p였다. 개선을 확인하지 못했으며 동등성도 입증하지 않았다.

G의 관측 성공 비율이 가장 높았지만 4/12는 실패해 완성된 도입 방식으로 선정할 수 없다. S1·SK의 성공 조건부 평균 시간은 더 짧았으나, 성공한 초기조건이 달라 전체 처리시간 단축으로 해석할 수 없다.

예측 개선은 좁은 조건에서 확인됐다. G의 실제 명령을 고정한 진단에서 seed 23·47의 SK는 S1보다 5·10단계 물체 위치 오차가 낮았다. seed 23의 5단계 평균은 약 0.0906→0.0586mm였지만 인계 성공은 S1 5/12, SK 4/12였다. seed 47은 둘 다 4/12였다. 같은 유효 창의 비교이나 겹치는 예측 창을 독립 시험으로 세지 않는다.

예약한 같은 범위 초기조건에서는 G만 성공하고 나머지 7개 모델·seed 조합은 시간 초과했다. 이 단일 조건은 본 비교에 합치지 않았다. 방법·통계는 [기술 보고서](technical_report.ko.md)에 정리한다.

## 5. 예측 개선이 성공으로 전달되지 않은 이유

**확인한 것은 개선이 전달되지 않은 지점이며 전체 실패를 설명하는 단일 원인은 아니다.** 예측 개선을 관측한 G 행동 분포와, 학습 계획기가 스스로 방문해 선택·실행하는 상태는 평가 범위가 다르다. 이 구조적 차이는 확인됐지만 분포 차이가 실패를 유발했다는 인과 주장은 가설이다.

G 경로의 고정 상태에서 16개 후보를 비교한 E1에서는 같은 seed·상태의 S1·SK 36쌍 중 **35쌍이 같은 후보**를 골랐다. 독립 초기조건은 6개다. 이 진단에서는 예측값 차이가 다른 행동으로 전달되는 경우가 드물었다. 온라인 128개 후보에서도 같았거나, 비용식이 원인이었다는 뜻은 아니다.

실패 63건 중 마지막 위치 조건 미충족은 **62건**, 방향 38건, 각속도 2건이었다. 조건은 중복되며 선속도 미충족은 없었다. 모든 실패를 정지·속도 문제로 설명할 수 없고, 종료 오차만으로 특정 예측·학습 자료를 원인으로 지목할 수도 없다.

| 확인한 관찰 | 미검증 원인 가설 | 구별할 후속 검사 |
|---|---|---|
| G 행동에서 예측 개선 | 학습 경로에서는 개선이 없을 수 있음 | 방문 상태의 공통 행동 예측 비교 |
| E1 35/36쌍 선택 일치 | 비용 순위·후보 차이에 둔감 | 예측·실제 비용과 순위 여유 연결 |
| S1 3건 전체 후보 예측 무효 | 예측 침투 오류 또는 복구 후보 부족 | 실패 직전 후보의 실제 기하 대조 |
| 순간 조건 만족 후에도 시간 초과 | 접근 시점·유지·계획 길이가 병목 | 개발 조건에서 한 요소씩 비교 |

S1의 세 종료는 128개 후보가 모두 예측 침투 검사에서 거절된 경우다. 실제 후보 대조는 미실험이므로 안전한 행동이 없었다는 증거는 아니다. G도 제한된 접촉면에서 복구 제안을 만들지 못한 사례가 있어, 구현의 행동 제약도 남아 있다.

G의 한 회전 사례는 마지막 위치 약 4.954mm·방향 약 0.119°로 네 순간 조건을 만족했지만, 유지 0.0825초가 0.3초에 못 미쳐 실패했다. 더 기다리거나 계획 길이를 늘리면 성공하는지는 미실험이다. 후속 가설 검사는 별도 개발 실험으로 기록하고 이번 실패나 동결 설정을 사후 변경하지 않는다.

## 6. 지금 가능한 사업·개발 결정

**학습 계획기의 현장 도입은 보류하고, 제어 방식 선택을 위한 기술 검증 결과로 활용한다.** 현재 조건에서는 G가 관측 성공과 계산 부담 측면에서 비교의 출발점이다. 실물 적용에는 접근·손상·센서 오차·후속 집기 검사가 필요하다.

학습 기반 개발을 계속할 이유도 남는다. 모델 확대 전에 같은 상태·후보에서 예측 오차·비용 순위·실제 움직임을 연결해 검사할 수 있다. 학습 기술의 구현과 효과 검증을 함께 유지한다.

사업 검토에는 특정 부품·인계 공차부터 확정해야 한다. 직접 집기, 지그·피더, 단순 제어, 학습 방식을 전체 공정의 성공·시간·재작업으로 비교해야 한다. 고객 수요, 정렬 필요 빈도, 비용 절감, ROI, 생산량 증가는 미검증이다. 기대효과는 검증할 항목이며 확보한 성과가 아니다.

## 7. 기여와 공개 문서의 사용 범위

프로젝트 책임자는 기술을 먼저 제안한 기획에 문제의 근거를 요구했고, 단순 제어 검증으로 기울었을 때는 학습 동역학을 다루려던 목표를 다시 분명히 했다. 예측과 작업 성공을 분리하고 개선이 불분명한 결과를 남기도록 방향을 정했다. Codex는 코드 작성·학습·실행·분석·문서화를 지원했다. 모든 코드를 본인이 작성했다는 의미로 쓰지 않는다.

남은 근거는 상태·행동·시간의 계약, 통제 비교, 실패를 포함한 분모, 예측과 행동 결과의 분리, 실행 재현 기록이다. 개인 역량은 설계 대안과 실패 가설, 조건 변경의 수정·검증을 직접 설명해 보여줘야 한다. 실물 제어·범용 월드모델·새 알고리즘의 역량을 이 프로젝트 하나로 주장하지 않는다.

이 문서는 적용 판단용이며 [기술 보고서](technical_report.ko.md)는 방법·통계·한계를 설명한다. 같은 결과를 다른 독자에게 전달한다. Markdown은 GitHub 열람·상대 링크·변경 이력을 위한 원본, PDF는 제출·독립 열람용이다. 본문에 핵심 결과와 가설을 직접 담아 첨부 Markdown 없이도 판단할 수 있게 했다. [근거 자료 목록](../artifacts/index.md)은 공개 파일과 포함·제외 범위를 안내하며, 공개 묶음에 전체 원시 실행이 포함됐다는 뜻은 아니다.
