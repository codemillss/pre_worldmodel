## 1. 비용보다 먼저, 접촉 전의 한 단계 운동 오차가 확인됐다

[직전 비용 비교](p4_handoff_cost_comparison.md)에서는 실제로 인계한 후보11을 모델이 놓치고, 실제로 움직이지 않은77을 인계 가능하다고 예측했다. 이번에는 같은 두 후보의 실제 상태·접촉·정지 구간을 대조하고, 매 단계에 실제 상태를 다시 넣어 한 단계만 예측했다.

**후보77은 실제1초 동안 푸셔와 부품의 접촉 기록이 없고 부품도 사실상 정지해 있었다. 실제 상태를 다시 입력해도 세 모델은 첫0.1초에 부품이0.365~0.414mm 움직인다고 예측했다.** 첫 입력부터 발생한 이 오차는 이후 재귀 누적만으로 설명할 수 없다. 후보11도 실제 접촉 전부터 운동을 예측했고, 실제 접근·접촉을 자유 예측의 경계 기하에서 재현하지 못했다.

동시에 첫 실측 푸셔 Y속도와 두 후보의 Y명령이 학습 자료의 관찰 범위를 넘었다. 속도 조건의 학습 지지 부족은 유력한 가설이다. 다만 후반 실제 정지 입력은 학습 자료에 가까워지고, 그 상태에서도 작은 잔차가 남으므로 **자료 범위·표현·학습 목적·모델의 기여를 하나의 원인으로 확정하지 않는다.**

이번 진단은 부품을 목표 위치·방향·낮은 속도에서0.3초 유지해 인계하려는 목적을 그대로 따른다. 비용·성공 문턱·후보 생성·모델 가중치는 변경하지 않았고 새 정렬 성공을 주장하지 않는다.

## 3. 실제 행동의 차이는 접촉 접근에서 나타났다

아래 시각은 모두 source99 이후다. 부품 이동은 두 경계의 XY 위치 차이 노름이며 경로 길이나 목표 오차와 구분한다.

| 실제 기록 | 후보11 | 후보77 |
|---|---|---|
| 첫 목표 XY속도(m/s) | +0.013674, +0.017514 | -0.003896, +0.029746 |
| 초기 푸셔-부품 간격 | 2.698801mm | 동일 |
| 첫0.1초 부품 이동 | 약9.58×10⁻¹²mm, 수치 잡음 수준 | 정확히 동일 |
| 첫0.1초 푸셔 이동 | 2.180778mm | 2.979619mm |
| 0.1초 말 간격 | 1.496132mm, 접근 | 3.194472mm, 더 멀어짐 |
| 푸셔-부품 활성 접촉 | 0.2125~0.5505초,677/2001표본 | 전체2001표본 중 접촉 entry 자체0 |
| 앞0.5초 부품 순이동 | 0.930687mm | 수치 잡음 수준 |
| 뒤0.5초 영 명령의 추가 순이동 | 0.033437mm | 수치 잡음 수준 |
| 실제 인계 | 0.9초 행동 경계, 원래 작업 경과10.8초 | 1초 안에 미충족 |

두 후보의 첫 명령은 서로 다르다. 물체는 첫0.2초 동안 같은 정지 상태지만 푸셔 궤적은 다르고,11의 이후 접촉에서 실제 부품 운동이 생긴다. 후보77의 비접촉은 정상력 임계값으로 작은 힘을 버린 결과가 아니라 접촉 entry가 없다는 관찰이다. 바닥의 부품 지지 접촉은 두 후보 모두 존재하며 옆면 접촉과 분리했다.

활성 접촉 기준은 개별 `normal_force_N > 0.001N`이다.11의 개별 정상력 최댓값0.062532N과 한 표본의 정상력 합 최댓값0.255175N은 다른 측정값이다. 저장된2010표본에는 구간 경계 중복9개가 있어, 물리 필드를 대조한 뒤 고유2001표본으로 접촉 분모를 계산했다. 모든 접촉의 비유한 값·1mm침투 초과·옆면 법선 방향 위반은0이다.

11은0.489초에 목표 자세 안으로 들어가고0.502초부터 속도까지 충족한다. 원시 유지0.3초는0.802초에 도달하지만 태스크의 성공 판정은 완료된 행동 경계에서 하므로0.9초가 인계 시각이다. 이 분석에서 성공 기준을 완화하지 않았다. [접촉·시각 독립 대조](p4_local_contact_review.json)에 출처18개와 원시 표본 수를 보존했다.

## 4. 실제 상태를 다시 넣어도 국소 오차가 남았다

자유 예측은 자기 예측을 다음 입력으로 사용한다. 이번 조건화 진단은 각 구간의 실제 상태를 다시 넣으므로 이전 단계의 예측 상태 오차를 입력에서 제거한다. 다음 표는 첫0.1초의 예측·실제 XY 위치 차이이며, 첫 입력은 자유 예측과 조건화 예측에서 같다.

| 첫 단계 부품 XY 오차 | Common11 | S1-11 | SK-11 |
|---|---|---|---|
| 후보11, 아직 실제 접촉 없음 | 0.477689mm | 0.562779mm | 0.664441mm |
| 후보77, 실제1초 내내 비접촉 | 0.364971mm | 0.414164mm | 0.410460mm |

이때 첫 단계의 재귀 입력 차이 항은 세 모델·두 후보 모두 정확히0이었다. 단지 늦은 다단계 예측이 누적돼서 시작된 실패는 아니다. 후보77은 실제 상태로 다시 시작하는 앞5전이에서도0.365~0.780mm의 한 단계 부품 오차가 남는다.

부호를 가진10차원 벡터에서 다음 관계를 별도로 검산했다.

`다음 자유 상태 오차 = 이전 자유 상태 오차 + (실제상태 조건화 증분 - 실제 증분) + (자유 증분 - 실제상태 조건화 증분)`

둘째 항은 국소 잔차, 셋째 항은 입력 상태가 달라져 모델 출력이 달라진 효과다. 이 항등식은 노름의 합이나 원인 비율이 아니다. 항들이 상쇄될 수 있고, 어느 상태 성분·학습 조건이 메커니즘의 원인인지는 별도 개입이 필요하다. 실제 전체 상태 재입력은 푸셔와 부품 상태를 함께 바꾸므로 푸셔 오차만의 기여를 분리한 실험도 아니다.

![후보11·77의 접촉 접근 기하와 실제 상태 재입력 후 국소 오차](figures/p4_local_contact_and_residual.png)

그림 위쪽은 저장된 경계 간격, 아래쪽 실선은 매 단계 실제 상태로 다시 시작한 한 단계 오차, 점선은 자유 예측의 해당 시각 누적 상태 오차다. 두 종류의 오차는 같은 지표로 성능 개선율을 계산할 대상이 아니다. 회색은 영 명령 구간,11의 연녹색은 실제 활성 접촉 기간이다. 선 연결은 경계 사이의 시각적 보간이다.

## 5. 정지 구간의 문제와 이미 누적된 오차를 구분했다

영 명령은 푸셔의 목표 속도를0으로 바꾸며 실측 속도를 순간적으로0으로 덮어쓰지 않는다. 후보77의 푸셔는 첫 영 명령0.1초 동안0.15mm 더 움직인 뒤 멈춘다. 후보11은 첫 영 명령 직후 접촉·감속과 부품의 작은 추가 운동이 남는다.

| 후보77의 정지 예측 | Common11 | S1-11 | SK-11 |
|---|---|---|---|
| 첫 영 명령0.5→0.6초, 국소 부품 XY 오차 | 0.081769mm | 0.159169mm | 0.099586mm |
| 실제 정지한0.6→0.7초, 국소 부품 XY 오차 | 0.013827mm | 0.024311mm | 0.013581mm |
| 같은0.6→0.7초, 국소 푸셔 XY 오차 | 0.190305mm | 0.225264mm | 0.207149mm |
| 자유 예측1초 말의 부품 XY 오차 | 1.897879mm | 1.758529mm | 1.655044mm |

실제 상태로 다시 입력하면 후기 국소 부품 오차는 작아지지만0은 아니다. 자유 예측의 큰 최종 오차는 앞선 운동 오차와 입력 변화까지 포함하므로 정지 구간만 학습하면 모두 해결된다고 말할 수 없다. 후보11의 후기 국소 푸셔 오차도 약0.277~0.333mm/단계 남았다.

기하도 대조했다. 실제11은0.2초에 간격0.173953mm로 접근하고0.3~0.5초 경계에서 접촉 기하를 보인다. 자유 예측의11은 같은0.2초에4.017~4.607mm 간격으로 실제 접근을 재현하지 못한다.77의 자유 예측 미래 경계도3.885~6.973mm로 모두 양수다. 따라서 “77을 가상 접촉시켜 움직인다고 예측했다”는 구체적인 메커니즘을 현재 결과로 확정하지 않는다. 예측 경계 간격은 접촉 힘 예측이 아니며, 경계 사이 접촉 유무까지 증명하지 않는다. [192개 기하값](p4_local_geometry_diagnostics.json)을 별도로 검산했다.

## 6. 학습 자료에서 확인한 지원 범위와 한계

검증·테스트 전이를 읽지 않고 원본train60에피소드의3200행만 재구성했다. 원래 train행 해시와 모든 정규화 통계가 정확히 같았다. 최근접 지표는 공유 정규화 scale로 나눈11특징의 RMS거리이며, 다른train family 최근접 거리 분포를 참조했다. 좌표별 min/max와 이 거리는 물리 validity나 일반화 판정기가 아니다.

| 학습 입력·명령 조건 | 이번 기록 | train에서 관찰한 양의 최댓값 |
|---|---|---|
| source99 실측 푸셔 Y속도 | 0.024790m/s | 0.014991m/s |
| 후보11 첫 적용 Y명령 | 0.017514m/s | 0.014991m/s |
| 후보77 첫 적용 Y명령 | 0.029746m/s | 0.014991m/s |

계획과 물리가 허용하는 명령이 관찰한 학습 좌표 범위를 넘어간다. 첫 입력의 최근접 RMS거리는11의1.164922,77의1.572749이며 참조 p95는0.329543이다. 이는 이 속도·기하 조합의 자료 부족 가설을 뒷받침하는 관찰이며, 자료 부족이 오차의 인과 원인이라고 입증한 것은 아니다.

정확한 영 명령train행은164/3200개이고 비영→영 전환114회도 있다. **“정지 자료가 없다”는 설명은 틀리다.** 다만 연속 영 명령의 최장은2단계0.2초이며, 전부 영 명령인K5 창은0개다. 이번0.5초 정지 접미부에 대응하는 연속 사례가 충분한지는 검토할 이유가 있다.

후기 실제 정지7~10단계의 입력은 관찰한 각 좌표 범위 안이고 최근접 거리도 참조 p95 안으로 돌아온다. 그때도 국소 잔차가 남는다. 초기의 좌표 범위 초과를 전 구간의 직접 입력 조건으로 일반화할 수 없으며, 공동·조건부 자료 지원의 충분성은 이 거리로 판정하지 않는다. 반대로77의 자유 예측 후기 입력은 최근접 거리만 보면 가깝지만 `obj_vx`가train최솟값 아래로 간다. 자료와의 거리·물리 정합·예측 정확도를 같은 판단으로 취급하지 않는다.

모델은 상대 푸셔 위치·sin/cos2yaw·물체속도·실측 푸셔속도·적용 명령을 입력한다. 명시적 접촉flag·힘·과거 행동은 없지만 고정 형상과 상대 좌표에서 접촉 관련 기하를 추론할 수 있다. flag를 안 넣은 사실만으로 표현 결함을 확정하지 않는다. Common/S1/SK의 schema·normalizer·자료 출처는 같고, 정지·인계 성공 라벨을 직접 학습하는 모델은 아니다. [train-only 분석과80개 입력](p4_local_input_support_review.json)을 남겼다.

[독립 검산](p4_local_independent_review.json)은 별도 scalar식으로 원래배열·상태증분·부호 분해·구간 평균/최댓값·192기하값을 대조했다. 수치 비교 수는 독립 상황의 수나 성능 신뢰도를 의미하지 않는다. 기존 비용 실험의890회귀는 원래 근거로 보존하고 이번에는 국소 분해의 새5검사를 수행했다. 전체895개를 이번에 실행했다고 기록하지 않는다.

다음 우선 질문은 **“지금 부족한 속도·비접촉 접근·정지 조건의 자료를 보완하면, 같은 모델과 같은 학습 예산에서 국소 오차와 인계 후보 판별이 달라지는가?”**다. 이를 검사할 좁은 자료 개입과 동일 예산 대조를 먼저 설계하는 것이 타당하다. 비용·특징·모델 크기까지 동시에 바꾸면 무엇이 개선 원인인지 구분하기 어렵다. 보완 자료·재학습·새 물리 실험은 이번에 실행하지 않았고, 원인 분리가 더 필요하면 푸셔만 실제 상태로 바꾼 진단을 별도 비교할 수 있다.

학습 기반 계획의 핵심은 유지한다. P5-01 설정 동결은 계속HOLD이며, 국소 오차 관찰을 실물 효과·일반화·원인 확정·개인의 직접 설명 역량으로 확대하지 않는다. 코드·추론·검산은Codex가 수행했고 개인 이해는NOT_ASSESSED다. 재현 시에는 기존run을 덮어쓰지 말고 등록해시와 원본보존을 확인해 새 출력 폴더를 사용한다.
