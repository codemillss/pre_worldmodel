# P4 보완 · 과거1차 모멘트를 제거해도 정지 손실은 증가하는가

2026-10-15 · **두 모드·8평가 완료 · KEEP·ZERO_M 모두 세 양의 배율에서 증가 · 과거 학습 원인 미확정 · P5-01 HOLD**

R1 최종 상태에서 비접촉 배치의 저장 Adam 방향을 같은 정지 배치에 적용했다. 과거1차 모멘트 m을 유지한 KEEP과, 과거 m만0으로 둔 ZERO_M을 비교했다. **ZERO_M의 증가폭은 더 작았지만 세 양의 배율 모두 정지 손실이 증가했다.** 이 고정 조건에서 과거 m의 조건부 기여를 관찰했으며, m을 제거하는 것만으로 증가가 사라지지는 않았다.

[공식 실행 요약](../runs/p4-first-moment-20261015-01/summary.json), [전체 두 모드·8평가](../runs/p4-first-moment-20261015-01/aggregate.json), [실행 전 등록](../configs/p4_first_moment.v1.json)과 [등록 사본](../runs/p4-first-moment-20261015-01/registration.json)을 보존했다. 원본 가중치·Adam은 바꾸지 않았다.

## 1. 같은 비접촉 기울기에서 과거 m만 달리했다

[직전 교차 배치 대조](p4_cross_batch_comparison.md)에서는 비접촉 방향이7상태·세 양의 배율의21개 측정 모두에서 정지 손실을 높였다. 이번에는 그중 R1·추가1000회 상태 하나로 좁혔다. 방향의 출처는 D11_noncontact이고, 손실을 측정하는 target은 동일한 D11_zero5 정지 학습 배치24창이다.

두 방향은 이전 진단에 저장된 total 방향을 그대로 읽었다. 동일한 비접촉 raw 기울기와 clipping 계수를 사용하며 새 기울기나 Adam 방향을 계산하지 않았다. KEEP은 저장 m을 유지하고, ZERO_M은 현재 기울기를 더하기 **전의 과거 m만0**으로 둔 방향이다. 현재 기울기의0.1 기여는 두 모드에 남는다.

```text
m_next = 0.9*m_or_zero + 0.1*gclip
v_next = 0.999*v + 0.001*gclip^2
theta_alpha = original_theta + alpha*stored_delta
```

저장2차 모멘트 v·누적 횟수 t·학습률·beta·eps는 같다. 저장 step2300에서 다음 step2301의 보정도 유지했다. ZERO_M은 전체 Adam 초기화나 현재 기울기의 제거가 아니다. 원래 이동량의 norm은 KEEP0.034990, ZERO_M0.031647이다. 크기를 맞추지 않았으므로 이 대조에는 이동 방향과 크기의 변화가 함께 포함된다.

각 모드의 alpha0·0.25·0.5·1을 같은 원본에서 독립 구성했다. 배율을 이어 적용하거나 원본에 갱신하지 않았다. 측정값은 `Lone + 0.1*Lroll + 0.2*(Lrelative_teacher + 0.1*Lrelative_free)`인 정규화된 무단위 공통 손실이다. 실제 정지 위치 오차나 물리 인계 성과를 측정한 값은 아니다.

## 2. 전체8평가: 두 모드 모두 증가가 남았다

아래는 같은 정지 target의 실제 공통 손실이다. 표는 소수6자리이며 판정에는 JSON의 원래 정밀도를 사용했다. alpha0은 기준점이다.

| alpha | KEEP | ZERO_M |
|---|---:|---:|
| 0 | 0.179262 | 0.179262 |
| 0.25 | 0.180433 | 0.179677 |
| 0.5 | 0.182107 | 0.180511 |
| 1 | 0.186957 | 0.183430 |

주판정은 각 모드의 실제 `Lstop(alpha)-Lstop(0)`이다. 수치 동률 범위는 기존 규칙인 `1e-6*max(1,abs(Lstop(0)))`을 유지했다. 양의6개 측정은 전부 INCREASE였고 동률·실패·해석 보류는0개였다. 두 모드·8평가·양의6개 자리 모두 보존했다.

alpha1의 기준 대비 증가량은 KEEP0.007695, ZERO_M0.004168이었다. alpha0.25와0.5에서도 ZERO_M의 증가폭이 KEEP보다 작았다. 따라서 **이 고정 target·기울기·v·t 조건에서 과거 m의 제거는 증가폭을 줄였지만, 증가를 없애는 충분조건은 아니었다.** 크기까지 바뀐 두 저장 방향의 비교이므로 방향각만의 효과로 분리하지 않는다.

KEEP의 네 배율은 이전 교차 대조의 매개변수·teacher/free 예측·전체 손실·상태를 정확히 재현했다. 두 모드의 alpha0도 서로 같고 이전 정지 기준 결과와 정확히 일치했다. 모든 전역 대조가 PASS였다. 이는 계산 경로의 일치 확인이며 독립 반복실험은 아니다. 기존 helper의 보조 복합 판정 INCONCLUSIVE는 위 실제 손실 증가 판정을 대체하지 않는다.

## 3. 검증과 해석의 범위

[관련 검사30개](p4_first_moment_validation.json)는 실행 계약6개·모드 연결12개·독립 감사12개로 모두 PASS다. [독립 감사3,313항목](p4_first_moment_independent_review.json)은 저장 예측·매개변수·손실·연결 정보·전역 대조와 분모를 검산했다. 감사 자체의 모델 forward·미분·optimizer·물리 실행은0회다. 전체 프로젝트 회귀검사나 새로운 학습 함수 실행을 뜻하지 않는다.

공식 실행은8평가·모델 forward48회·행 처리1920회였다. 평가마다 teacher120행과 free24행씩5회를 처리했다. 실행 전 입력748개를 해시로 고정했고 새 출력10개와 색인 자체를 포함한11개 파일을 보존했다. [출력 색인](../runs/p4-first-moment-20261015-01/artifact_hashes.json)에서 해당 바이트를 확인할 수 있다.

원본 가중치·Adam·모드·gradient 저장 공간·RNG·입력·normalizer는 불변이었다. 새 미분·학습·optimizer 생성/step·물리 실행·checkpoint 저장은 모두0회다. 새 자료·normalizer 재적합·개발/validation·최종 test는 사용하지 않았다.

이 결과만으로 남은 증가를 v 때문이라고 정하거나, 과거 실제 학습의 정지 악화 원인을 확정할 수 없다. 하나의 최종 상태와 학습 배치에서 얻은 비독립 측정이며 실제 기록 배치의 혼합·연속 갱신·전체 학습 경로를 재현하지 않았다. Adam 초기화·학습률 변경·모델 승격의 근거로 채택하지 않는다.

후속 질문은 아직 정하지 않았으며 추가 대조는 미등록·미실행이다. 기존 최종1000회 실패와 혼합 결과를 보존한다. 전체23/28·**P5-01 HOLD / NOT_RUN**, 실제 정렬 개선 NOT_EVALUATED·개인 이해 NOT_ASSESSED를 유지한다.
