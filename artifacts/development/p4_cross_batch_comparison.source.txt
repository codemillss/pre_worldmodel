# P4 보완 · 다른 학습 배치의 방향이 정지 손실에 미치는 영향

2026-10-15 · **28조건·112평가 완료 · 비접촉 방향의 정지 손실21/21 증가 · 자기 정지 방향20/21 감소 · 과거 원인 미확정 · P5-01 HOLD**

같은 모델 상태에서 다른 학습 배치로 계산한 저장 Adam 방향을, 동일한 정지 배치에 적용했다. 비접촉 배치의 방향은7상태·세 양의 배율 모두에서 정지 손실을 높였다. 정지 배치 자신의 방향은21개 중20개에서 낮췄다. **선택한 조건에서 자기 배치의 손실 감소가 정지 손실 감소를 보장하지 않음을 확인했다.** 이것이 과거 R1 학습의 정지 악화를 일으켰는지는 확인하지 않았다.

공식 [실행 요약](../runs/p4-cross-batch-20261015-01/summary.json), [전체28조건·112평가](../runs/p4-cross-batch-20261015-01/aggregate.json), [실행 전 등록](../configs/p4_cross_batch.v1.json)과 [등록 사본](../runs/p4-cross-batch-20261015-01/registration.json)을 보존했다. 원본 가중치·Adam은 불변이고 새 미분·학습·물리 실행·모델 승격은 없었다. 실제 정렬 개선·개인 이해는 NOT_EVALUATED·NOT_ASSESSED다.

## 1. 자기 배치 대조에서 남은 질문

프로젝트의 목표는 부품을 목표 자세에 멈추게 할 행동을 학습한 미래 움직임으로 선택하는 것이다. [상대항 학습 대조](p4_relative_loss_comparison.md)에서는 최종 R1의 정지 상대기하 예측이 악화했다. 그러나 [자기 배치의 유한 걸음 대조](p4_finite_step_comparison.md)에서 R1 최종 정지 손실은 세 양의 배율 모두 감소했다. 그 배치의 한 걸음 overshoot만으로 과거 악화를 설명할 수 없었다.

학습은 여러 종류의 배치를 섞어 진행했다. 이번 질문은 **다른 배치에서 계산한 같은 저장 방향이 정지 배치의 손실을 높이는가**다. 다른 배치의 방향을 계산하는 자료를 source, 실제 손실을 측정하는 정지 배치를 target이라 구분했다. source와 target의 손실·기울기를 섞어 읽지 않는다.

## 2. 방향만 바꾸고 같은 정지 배치를 평가했다

공통 출발점과 C0/R1의 추가100·500·1000회, 총7상태를 사용했다. source는 과거 첫 배치·정지·접촉 전환·비접촉의 네 종류다. 모든 target은 같은 상태의 D11_zero5, 즉24가족의 실제 상태10부터 영 명령5개인 학습 정지 배치다. source 자료를 이번 예측의 입력으로 넣지 않았다.

같은 snapshot·같은 alpha에서는 출발 가중치·target·normalizer·손실을 유지하고 source의 저장 total+KEEP 이동량 delta만 달리했다. alpha는 기존0·0.25·0.5·1을 그대로 사용했다. 각 복사본을 같은 원본에서 독립 구성했고 배율을 이어 적용하거나 방향·Adam을 새로 계산하지 않았다.

```text
theta_alpha = theta + alpha*delta_source
Lstop = Lone + 0.1*Lroll + 0.2*(Lrelative_teacher + 0.1*Lrelative_free)
```

모든 값은 정규화된 무단위 공통 손실이다. C0·공통 상태에도 상대항을 가상 적용한 값이며 그들의 과거 실제 학습 목적함수가 아니다. 네 source의 원래 벡터 크기를 유지했다. 따라서 비교에는 방향과 크기가 함께 포함되며 방향각만의 효과로 부르지 않는다.

실행 전 다음 대조 조건을 고정했다.28조건의 네 배율 매개변수가 이전 자기 배치 실험의 해당 source 복사본과 bitwise 같아야 한다. 자기 정지7조건은 이전 네 배율의 예측·손실을 재현해야 한다. alpha0은28조건 모두 이전 정지 결과를 재현하고, 같은 상태의 네 source 사이에서도 같아야 한다. **이 조건을 모두 정확히 통과했다.** 추가 독립 반복실험이 아닌 계산 경로 대조다.

수치 실패·alpha0 재현 실패는 조건 전체의 해석을 보류하고 자리를 유지하도록 했다. 전역 대조가 틀리면 전체 주효과 집계를 null로 남기는 규칙도 등록했다. 이번에는 실패0개로28조건·112평가가 완결됐다.

## 3. 주결과: 각 배율의 실제 정지 손실 변화

주지표는 실제 `Lstop(alpha)-Lstop(0)`이다. `1e-6*max(1,abs(Lstop(0)))` 이내만 수치 동률로 두었다. 기존 helper의 복합 overshoot 판정은 보조 기록이다. 모든 양의 배율에서 정지 손실이 증가해도 그 복합 판정은 INCONCLUSIVE일 수 있으므로, 이를 교차 악화가 없다는 뜻으로 읽지 않았다.

아래는 각 source의7상태에서 **정지 손실이 증가한 수**다. 각 칸의 분모는7이며 나머지는 감소했다. 양의84개 측정에서 동률·해석 보류는 없었다.

이전 자기 배치 대조와 연결하면, 다른 source의63개 중32개는 source 손실이 감소하면서 정지 target 손실은 증가했다. 비접촉에서는21개 중14개가 이 경우였다. source에서조차 실패한 걸음만으로 교차 증가를 설명할 수 없으며, 이 집계도 동일한 매개변수 복사본에 대한 관측이다.

## 4. R1 최종 상태에서는 자기 손실과 교차 영향을 구분할 수 있었다

R1·1000회 상태의 공통 정지 기준 손실은 모든 source에서0.1792617405였다. 아래는 각 방향을 적용한 **정지 target의 실제 손실**이다.

| source 방향 | alpha0.25 | alpha0.5 | alpha1 |
|---|---:|---:|---:|
| 과거 첫 배치 | 0.167484 | 0.156328 | 0.135872 |
| 자기 정지 | 0.156585 | 0.135776 | 0.099706 |
| 접촉 전환 | 0.171607 | 0.164247 | 0.150406 |
| 비접촉 | 0.180433 | 0.182107 | 0.186957 |

비접촉 방향의 alpha0.25에서는 source인 비접촉 배치의 자기 손실이 이전 대조에서0.01045655→0.00383618로 감소했다. **동일한 매개변수 복사본**을 정지 target에 적용하자0.17926174→0.18043342로 증가했다. 한쪽 배치의 개선과 다른 조건의 악화가 함께 나타난 구체적 사례다. 물리 정렬 성능의 상충을 측정한 것은 아니다.

자기 정지 방향은 앞 대조와 같은0.099706까지 감소했다. 이 두 관측은 '정지 배치의 자기 방향이 나쁘다'와 '다른 배치의 방향이 정지 손실을 높일 수 있다'를 구분한다. 과거 실제 샘플 순서·노출·누적 갱신의 효과는 아직 이 비교에 포함되지 않는다.

## 5. Taylor 해석에도 target 기울기를 사용했다

source 기울기는 방향의 출처다. 이번 정지 손실의1차 근사에는 **같은 snapshot의 정지 raw total 기울기**를 사용했다. source 기울기를 넣으면 다른 손실의 미분을 계산하게 된다. 실제 판정은1차 근사가 아닌 위 실제 손실 차이로 결정했다.

기존 등록대로 float32 `theta_alpha-theta`를 float64로 올린 차분을 주 Taylor 기준으로 유지했다. 두 float32 끝점을 각각 float64로 올려 뺀 민감도 값과 명목상 `alpha*(gstop·delta_source)`도 분리했다. 새 미분은 없고 이 참고 산술로 판정을 바꾸지 않았다.

비접촉 방향의 정지1차 변화는 양의21개 중18개에서 양수였다. R1·500회의3개는 음수인데도 실제 정지 손실은 모두 증가했다. 따라서21개 증가를 전부 같은 국소 기울기 충돌로 설명할 수 없다. 출발점의 방향 관계와 유한 크기의 비선형 변화가 모두 남는다.

## 6. 실행·독립 검산과 주장 범위

[관련 검사43개](p4_cross_batch_validation.json)는 실행 계약7개·routing wrapper16개·독립 감사20개로 모두 PASS다. 기존 수치 helper는 그대로 재사용했다. source/target 혼동 거부·같은 상태의 연결·고정 분모·전역 대조 실패 시 집계 보류 등을 합성 자료로 확인했으며 전체 프로젝트 회귀검사는 아니다.

[독립 감사25,376항목](p4_cross_batch_independent_review.json)은 저장 출력에서 손실을 재계산하고 target 기울기·source 매개변수 복사본·모델 호출 trace·자기 대조·주효과 집계를 검산했다. 감사의 모델 forward·미분·optimizer·물리 실행은0회다. 학습 함수를 다시 추론한 검사가 아닌 저장 출력의 독립 산술 검산이다.

공식 실행은112평가·모델 호출672회·행 처리26,880회였다. target24창마다 teacher120행과 free24행씩5회를 사용했다. 원본 가중치·Adam·모드·gradient 저장 공간·RNG·입력·normalizer는 불변이었다. 새 미분·학습·optimizer instance/step·물리 조회·checkpoint·새 자료·개발/validation·최종test는 모두0회 또는 미사용이었다.

실행기 시간3.219425초·최대 RSS417529856B·실행 폴더16348504B와88개 출력 색인을 보존했다. 준비·검사·감사·문서 시간은 실행 시간과 구분한다. [자원 계획](p4_cross_batch_resource_plan.json)의 실행64MiB·문서64MiB·남은 공간2GiB 기준을 유지했고 추가 유료 사용·원본 삭제는 없었다.

다른 source의 원래 이동량이 정지 손실을 높일 수 있다는 국소 관측을 확보했다. 다만 source의 구성·기하·벡터 크기가 달라 배치 유형이나 방향각만의 원인으로 분리하지 않는다. 모델 상태 간 비교도 가중치와 이력이 함께 다르다.

**다음 검토 후보**는 R1 최종 비접촉의 raw 기울기·2차 모멘트 v·누적 횟수 t·정지 target을 고정하고, 저장1차 모멘트를 유지한 KEEP과 m만0으로 둔 ZERO_M의 방향에서도 정지 증가가 유지되는지 비교하는 것이다.1차 모멘트의 조건부 기여를 더 좁혀 보는 질문이며 아직 미등록·미실행이다. 실제 기록 배치의 혼합이나 누적 학습 전체의 원인을 이미 분리했다는 뜻은 아니다.

과거 R1의 정지 악화 원인·독립 일반화·실제 정렬 개선은 미확정이다. C0/D11·R1의 최종1000회 실패와 혼합 결과를 보존하고 모델·학습률을 승격하지 않는다. 전체23/28·P4 기존4/4·**P5-01 HOLD / NOT_RUN**과 개인 이해 NOT_ASSESSED를 유지한다.
