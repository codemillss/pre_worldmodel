# P4 보완 · 접촉 경계와 정지 누적 오차 진단

2026-10-14 · **저장 기록 진단·독립 검산 완료 · 인과 원인 미확정 · 전체 23/28 · P5-01 HOLD**

직전 5군 재학습에서 공통으로 무효가 된 접촉 전이와 D10의 정지 실패 두 사례를 분석했다. 접촉 전이에서는 부품·푸셔의 위치 오차가 같은 침투 방향으로 작용했다. 정지 구간에서는 작은 한 단계 잔차와 예측 입력이 달라진 뒤의 추가 증분 차이가 함께 쌓였다. 고속 자료로 학습 입력의 거리는 작아졌지만, 가장 가까운 실제 학습 사례도 접촉 시작 간격과 정답 움직임이 달랐다. **실패의 형태는 좁혔으며, 자료·표현·손실 중 어느 하나가 유일한 원인인지는 확정하지 않았다.**

공식 실행은 [p4-mechanism-20261014-01](../runs/p4-mechanism-20261014-01/summary.json)이다. [실행 전 등록](../runs/p4-mechanism-20261014-01/registration.json), [접촉 기하 분해](../runs/p4-mechanism-20261014-01/contact_geometry.json), [정지 오차 분해](../runs/p4-mechanism-20261014-01/stop_propagation.json), [학습 입력 지원](../runs/p4-mechanism-20261014-01/input_support.json), [원본 색인](../runs/p4-mechanism-20261014-01/artifact_hashes.json)을 함께 보존했다. [이전 자료 보완 비교](p4_data_retraining_comparison.md)의 Y/S 주효과 판정 HOLD_INVALID_PRIMARY와 모델·자료·성공 문턱은 유지했다.

## 1. 이번에 확인한 질문과 실행 범위

첫 질문은 **실제 상태를 입력한 접촉 한 단계에서, 어느 출력 성분의 오차가 과도한 겹침을 만드는가**다. 대상은 개발 f001·Y1·S0의 core 상태 1→2, 다섯 군 R·D00·D10·D01·D11이다. 같은 초기조건의 S1 첫 구간은 동일하므로 중복해 세지 않았다.

두 번째는 **실제 상태를 매번 넣으면 유효한 정지 예측이, 연속 예측에서는 어떻게 무효가 되는가**다. D10의 개발 f001·f010, Y0·S1에서 실제 상태 10을 시작으로 영 명령 5개를 넣은 기록을 사용했다. 자유 예측과 실제 상태 조건화 예측을 각 단계의 같은 실제 끝상태와 비교했다.

세 번째는 **공통 접촉 실패 입력과 가까운 학습 전이는 얼마나 있었고, 무엇이 비슷하거나 달랐는가**다. 기존 모델의 실제 11개 입력과 동결 정규화를 그대로 사용했다. 절대 세계 위치를 임의로 거리 항에 추가하지 않았다.

선택된 개발 가족은 2개다. 접촉 5행과 정지 2사례×5단계×2모드=20행은 진단용 25행이며 독립 실험 25개가 아니다. 이 사례들은 이전 비교 결과를 보고 선택한 실패다. [방법 계약](../configs/p4_error_mechanism.v1.json)을 새 분석 실행 전에 고정했지만, 결과를 모르는 독립 시험이나 인과 실험의 사전등록으로 주장하지 않는다.

저장된 상태·증분·실제 기록만 사용했다. 학습 갱신·새 모델 예측·물리 실행은 모두 0회다. 실제 학습 모델 호출, checkpoint 로딩, 역전파와 다섯 종류의 물리 엔진 호출을 막는 실행 가드를 두었고 시도 계수도 전부 0이었다. Torch RNG도 변하지 않았다. 기존 모델 결과를 다른 기준으로 다시 성공 처리한 것은 아니다.

## 2. 접촉 실패는 위치 오차의 방향으로 설명된다

실제 부품과 푸셔의 표면 간격은 +0.009288mm에서 -0.075257mm로 바뀌었다. 실제 접촉 기록도 전환 구간이었다. 반면 다섯 모델 모두 다음 간격을 -1mm 미만으로 예측해 기존 침투 문턱을 위반했다.

부품 XY·푸셔 XY·부품 방향의 실제/예측 값을 바꿔 만든 8개 조합에서 간격 함수를 계산했다. 교체 순서에 따른 기여를 평균해 간격 오차를 세 블록에 배분하고, 2차·3차 상호작용도 보존했다. 아래 값은 **이 끝상태 쌍의 기하 오차를 대수적으로 나눈 결과**이며 학습 원인의 비율이 아니다. 음수는 실제보다 더 깊게 겹치는 방향이다.

| 군 | 예측 간격 (mm) | 부품 XY 배분 (mm) | 푸셔 XY 배분 (mm) | 방향 배분 (mm) |
|---|---|---|---|---|
| R | -1.004378 | -0.188658 | -0.766312 | +0.025849 |
| D00 | -1.714052 | -0.626921 | -1.011954 | +0.000080 |
| D10 | -1.311373 | -0.370918 | -0.865257 | +0.000058 |
| D01 | -1.806959 | -0.632406 | -1.099488 | +0.000192 |
| D11 | -1.257610 | -0.375488 | -0.806993 | +0.000128 |

각 행의 세 배분 합은 예측 간격에서 실제 간격 -0.075257mm를 뺀 값과 일치한다. 보완군에서 방향의 기하 기여는 매우 작고 두 위치 블록은 모두 침투를 키웠다. **이 접촉 실패를 회전 오차만의 문제로 보는 설명은 맞지 않는다.** 다른 태스크나 모든 회전 예측으로 일반화하지 않는다.

실제 끝상태의 접촉 법선으로 위치 오차를 투영한 보조 계산도 남겼다. D11의 부품 XY 오차 크기는 0.379572mm, 푸셔는 0.874388mm였다. 두 물체의 오차가 상대 기하에서 같은 방향으로 작용해 약 1.182353mm의 간격 오차가 됐다. R은 큰 접선 방향 오차와 약 0.052385mm의 비선형 잔차가 있어 1차 근사와 정확한 배분을 구분했다. 단순한 오차 크기의 합이나 평균만으로 접촉 간격을 판단하지 않는다.

재조합한 상태는 기하 함수의 진단 입력일 뿐이다. 실제로 실행 가능한 상태, 모델에 다시 넣어 예측한 결과, 접촉력의 증명으로 해석하지 않았다. 속도는 순간 간격 함수의 직접 입력이 아니지만 이후 모델 출력에는 영향을 줄 수 있으므로 속도 문제를 배제하지 않는다. 미분이 유일하지 않은 점과 보수적으로 기울기 계산을 유보한 근접 경계도 구분했다.

## 3. 정지 실패는 국소 잔차와 추가 차이가 함께 누적된다

두 정지 사례 모두 실제 접촉 유형은 첫 전이가 전환이고 이후 4전이는 비접촉이었다. 영 명령은 실제 속도를 즉시 0으로 덮는 조작이 아니다. 매번 실제 상태를 입력한 한 단계 예측 10개는 유효했지만, 연속 예측은 두 사례 모두 다섯 번째 단계에서 무효가 됐다.

| 사례·모드 | K1 간격 (mm) | K2 | K3 | K4 | K5 |
|---|---|---|---|---|---|
| f001 실제 상태 | -0.003055 | -0.000160 | -0.000170 | -0.000171 | -0.000171 |
| f001 실제 입력 한 단계 | -0.055981 | -0.033218 | -0.035064 | -0.035080 | -0.035078 |
| f001 연속 예측 | -0.055981 | -0.178040 | -0.425561 | -0.736617 | **-1.101760 무효** |
| f010 실제 상태 | -0.003418 | +0.000004 | -0.000002 | -0.000002 | -0.000002 |
| f010 실제 입력 한 단계 | -0.088034 | -0.071000 | -0.072391 | -0.072391 | -0.072390 |
| f010 연속 예측 | -0.088034 | -0.247967 | -0.552136 | -0.923394 | **-1.351205 무효** |

실제 상태 조건화 예측은 서로 독립적인 한 단계 결과다. 위 행을 연결해 새로운 연속 예측으로 해석하지 않는다. 첫 입력은 두 모드에서 정확히 같았으며 첫 예측 증분 차이도 두 사례 모두 0이었다. 이후 입력이 달라진 상태에서 증분 차이가 추가됐다.

각 10차원 성분에서 다음 식을 저장 증분으로 검사했다.

`다음 상태 오차 = 이전 상태 오차 + (실제 입력 예측 증분 - 실제 증분) + (연속 예측 증분 - 실제 입력 예측 증분)`

첫 괄호는 실제 입력에서도 남는 국소 잔차, 두 번째는 입력이 달라진 뒤 저장 예측의 추가 차이다. 방향은 기존 2π 순환을 적용해 재구성했고 원시 증분과 상태 적분의 정합을 따로 확인했다. 벡터 항이 닫힌다는 사실을 오차 크기의 가산성이나 유일한 인과 귀속으로 바꾸지 않았다. 두 모드의 배치 크기 24·120도 다르므로 수치 연산 차이가 들어갈 가능성은 한계로 남긴다.

첫 영 명령에서 이미 부품 위치 오차는 f001 0.215723mm·f010 0.250666mm였다. 실제 상태를 매번 넣어도 오차가 0인 것은 아니다. 이후 작은 국소 잔차와 추가 증분 차이가 함께 쌓였고, K5의 부품·푸셔 XY 오차는 f001 1.136784·2.883980mm, f010 1.311766·2.633636mm가 됐다.

K5 간격 오차 배분은 f001에서 부품 -0.762264·푸셔 -0.336688·방향 -0.002638mm, f010에서 부품 -0.901703·푸셔 -0.442693·방향 -0.006808mm였다. 푸셔의 전체 XY 오차가 더 크더라도, 이번 간격 오차에는 부품 위치의 기여가 더 컸다. **어느 방향으로 틀렸는지와 두 물체의 상대 이동을 함께 살펴야 한다.** 무효인 K5 끝상태는 유한하므로 진단에 사용했지만 유효 예측이나 주평가 평균으로 복원하지 않았다. 실패 이후의 결측도 이어 예측하거나 채우지 않았다.

## 4. 가까운 학습 입력이 생겨도 접촉 경계 지원은 별개다

실제 모델은 푸셔-부품 상대 XY, 방향의 sin2θ·cos2θ, 부품 속도 3개, 푸셔 속도 2개, 적용 명령 2개로 된 11입력을 사용한다. 원래와 같은 Torch float64 인코딩·정규화 후 float32 모델 경계 값을 만들었다. 이 공간의 등좌표 가중 L2 거리를 고정했으며, 고유 전이 ID의 중복을 제거한 뒤 최근접 10개를 선택했다. 정규화나 거리 가중치를 결과에 맞춰 조정하지 않았다.

| 군 | 최근접 거리 | 쿼리의 단변량 범위 밖 항 | 최근접 전이의 teacher 입력 노출 | rollout 실제 시작 노출 |
|---|---|---|---|---|
| R | 14.3450 | 상대 X/Y·푸셔 Vy·명령 Vy | 107 | 21 |
| D00 | 3.7231 | 푸셔 Vy·명령 Vy | 63 | 21 |
| D10 | 0.8673 | 없음 | 42 | 21 |
| D01 | 3.7231 | 푸셔 Vy·명령 Vy | 63 | 21 |
| D11 | 0.8673 | 없음 | 42 | 21 |

거리에는 물리 단위가 없으며 모델의 기존 입력 스케일에 따른 값이다. 0.8673을 충분한 자료나 분포 안이라는 문턱으로 사용하지 않는다. 단변량 범위 안이라는 사실도 입력의 조합과 접촉 반응이 충분히 지원된다는 뜻은 아니다.

D10·D11의 가장 가까운 전이는 학습 f013·Y1의 core 두 번째 전이였다. 그 입력의 부품-푸셔 간격은 1.29493mm였지만 실패 쿼리는 0.009288mm였다. 실제 부품 ΔY는 0.13274mm와 0.69375mm, 푸셔 ΔY는 1.59128mm와 0.77838mm로 달랐다. 가까운 입력에서도 접촉 시작까지의 거리와 실제 다음 움직임이 달랐다. 이 최근접 거리의 제곱합 중 약 88.49%는 푸셔 속도·명령, 10.94%는 상대위치 성분이었다. **고정 입력 거리의 가깝다는 판단과 접촉 경계의 유사성을 구분해야 한다.**

R은 고유 전이 3200개·60가족, 각 보완군은 기존 3183+신규480=3663개·84가족이었다. 겹치는 K5창의 일부를 바꿨기 때문에 고유 전이가 순증했지만 학습창 2960개와 학습 예산은 동일했다. 최근접 10개가 속한 가족도 R은 기존 1가족, D00·D01은 신규 4가족, D10·D11은 신규 5가족이었다. 가까운 창이나 같은 궤적을 독립 표본 수로 늘리지 않는다.

teacher 노출은 실제 상태를 넣는 한 단계 학습에서의 출현 횟수다. rollout 실제 시작 노출은 K5의 시작 상태로 사용한 횟수다. 이후 rollout 입력은 모델의 예측 상태이며, 정답 전이가 자료에 반복 등장했다는 이유로 같은 실제 상태를 반복 입력했다고 할 수 없다. 전체 군별 횟수는 teacher 314,960·rollout 시작 62,992로 같았다. 횟수는 최적화 영향이나 손실의 총 가중치와 동일하지 않다. float64와 float32 거리 순위의 민감도도 보조로 기록했고 각 군의 최근접 10개 순서는 같았다.

| EM-07 원인 귀속 | 국소·추가 오차의 구분, 한계 보존 | 기하·전파 형태는 구별,유일 원인 미확정 | PARTIAL | 사례 선택·수치·지원 한계 |
| EM-08 성능 동결 | 별도 성능 근거로 판단 | 새 행동·최종 test 없음,주효과 HOLD 유지 | HOLD | 기존 결과·P5 상태 |

[관련 단위 검사 82개](p4_error_mechanism_validation.json)는 신규 37개와 기존 표현·접촉·평가 45개다. 초기 검사 실행의 소스 경로 누락은 import 단계 오류로 보존했고 경로를 맞춘 검사만 완료 근거로 사용했다. 패키지 추가 설치나 생산 코드 변경은 없었다. 전체 프로젝트 검사를 재실행했다는 뜻은 아니다.

[독립 검산](p4_error_mechanism_independent_review.json)은 원래 간격 수식을 복사하지 않고 회전 사각형 네 변까지의 거리로 기하를 계산했다. 216개 조합, 교체 순서 평균, 상태·증분·yaw, 입력 순위·중복·노출과 출처를 재계산해 4986개 항목을 통과했다. 검사 항목 수는 독립 실험 수가 아니다. NumPy로 재구성한 float32 입력의 순위는 검사했지만 Torch/NumPy의 cast 이전 수치 민감도 자체까지 독립 재실행한 것은 아니다.

공식 진단 실행은 약 1.09초, 결과는 색인 포함 781,447바이트였다. 등록 당시 남은 공간 약 2.642GB에서 실행했고 [자원 계획](p4_error_mechanism_resource_plan.json)의 결과 16MiB·문서 64MiB·여유 2GiB 기준을 확인했다. 등록·단위 검사·검산·그림·문서 시간은 이 실행 시간에 포함하지 않는다. 문서 갱신 후 실제 남은 공간은 [최종 자원 기록](p4_error_mechanism_resource_result.json)에 별도로 남긴다.

## 6. 다음 변경을 고를 근거

이번 진단은 “오차가 누적된다”에서 더 나아가 어느 출력과 상대 기하가 틀렸는지, 실제 입력에서도 무엇이 남는지, 가까운 자료가 접촉 경계에서 무엇을 놓치는지를 확인했다. 그렇지만 같은 모델·자료를 새로 바꾸지 않았으므로 자료와 학습 방법의 인과 효과를 분리한 결과는 아니다. 정렬 개선·독립 일반화·현업 효과와 개인 이해도도 별도 확인이 필요하다.

접촉 간격은 현재 11입력의 상대위치·방향에서 이미 계산할 수 있다. 따라서 단순히 “접촉 정보가 입력에 없다”고 단정할 수 없다. 다음에는 **같은 자료·구조·예산에서 상대위치·간격 오차를 학습 목표에 더 직접 반영하는 한 가지 변경**을 검토할 근거가 있다. 이는 개별 위치 오차와 상대 기하 오차가 다르게 평가되는 문제에 대응하는 가설이다. 또 다른 가설은 현재 수집 자료에서 접촉 직전의 매우 작은 간격 조건이 덜 지원된다는 것이다. 이 경우 경계 주변 자료를 먼저 정밀하게 확인하거나 보완해야 한다.

두 변경을 한 번에 적용하면 원인을 구별하기 어렵다. 후속 대조 전에 변경 한 개·학습 예산·손실 가중치·평가 분모와 기하 무효 처리부터 별도로 고정한다. 현재는 기존 모델·문턱을 유지하며 P5-01 동결과 Y/S 성능 우위 결론을 보류한다. 이번 진단을 새로운 정식 단계로 세지 않아 전체 23/28·P4 4/4는 그대로다.
