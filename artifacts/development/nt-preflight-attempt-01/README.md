# 첫 N-T 사전 검사: 보존된 실패 이력

2026-10-22 첫 시도는 모델·정규화 파일 수를 24개로 단정한 검사에서 중단됐다. 원래 D2의 실제 파일 지도는 22개이며, 모델 7개나 가중치 변경은 없었다. 실제 후보 미래는 실행하지 않았다.

- `executor.py`, `test_executor.py`: 첫 실행 당시 코드를 바이트 그대로 보존한 사본이다. 현재 실행 진입점이 아니다.
- `incomplete.portable.json`: 로컬 실패 기록의 비공개 경로만 바꾼 파생본이다. 원본 SHA와 정정 범위는 아래 정정 기록에 있다.
- [정정 기록](../../validation/nt_preflight_binding_correction.v1.json): 2.572초·81,769B를 다음 시도의 누적 예산에 포함한 근거와 실제 전체 파일 해시 지도.
- [현재 결과](../../../docs/nt_fullbank_preflight.ko.md): 새 버전·새 결과 폴더에서 검사를 완료한 기록.

기존 실패 원본은 로컬에 보존했으며 덮어쓰기나 자동 재시도는 하지 않았다. 최초 단위 검사 통과와 설계 검토 통과만으로 실제 결합 정확성이 확인된 것으로 보지 않는다.
